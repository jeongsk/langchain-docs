**LangGraph v1은 에이전트 런타임의 안정성에 초점을 맞춘 릴리스입니다.** 핵심 그래프 API와 실행 모델을 그대로 유지하면서, 타입 안정성, 문서, 개발자 경험을 개선했습니다.

[LangChain v1](/oss/releases/langchain-v1)과 함께 사용할 수 있도록 설계되었으며(LangChain의 `create_agent`는 LangGraph 기반으로 구축됨), 높은 수준에서 시작하여 필요할 때 세밀한 제어로 전환할 수 있습니다.

<CardGroup cols={1}>
    <Card title="안정적인 핵심 API" icon="diagram-project">
        그래프 기본 요소(상태, 노드, 엣지)와 실행/런타임 모델이 변경되지 않아 업그레이드가 간단합니다.
    </Card>
    <Card title="기본적으로 제공되는 신뢰성" icon="database">
        체크포인팅, 영속성, 스트리밍, 휴먼 인 더 루프를 통한 내구성 있는 실행이 계속해서 일급 기능으로 제공됩니다.
    </Card>
    <Card title="LangChain v1과의 원활한 통합" icon="link">
        LangChain의 `create_agent`는 LangGraph에서 실행됩니다. 빠른 시작을 위해 LangChain을 사용하고, 맞춤형 오케스트레이션이 필요할 때 LangGraph로 전환할 수 있습니다.
    </Card>
</CardGroup>

업그레이드하려면,

<CodeGroup>
```bash pip
pip install -U langgraph
```
```bash uv
uv add langgraph
```
</CodeGroup>

## `create_react_agent`의 지원 중단

LangGraph의 `create_react_agent` 사전 빌드는 LangChain의 `create_agent`로 대체되어 지원이 중단되었습니다. 더 간단한 인터페이스를 제공하며, 미들웨어 도입을 통해 더 높은 커스터마이징 가능성을 제공합니다.

* 새로운 `create_agent` API에 대한 정보는 [LangChain v1 릴리스 노트](/oss/releases/langchain-v1#create-agent)를 참조하세요.
* `create_react_agent`에서 `create_agent`로 마이그레이션하는 방법은 [LangChain v1 마이그레이션 가이드](/oss/migrate/langchain-v1#create-agent)를 참조하세요.
