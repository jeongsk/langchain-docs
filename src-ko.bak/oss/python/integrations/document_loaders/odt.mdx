---
title: Open Document Format (ODT)
---

>[Open Document Format for Office Applications (ODF)](https://en.wikipedia.org/wiki/OpenDocument)는 `OpenDocument`로도 알려져 있으며, ZIP으로 압축된 XML 파일을 사용하는 워드 프로세싱 문서, 스프레드시트, 프레젠테이션 및 그래픽용 오픈 파일 형식입니다. 오피스 애플리케이션을 위한 개방형 XML 기반 파일 형식 사양을 제공하는 것을 목표로 개발되었습니다.

>이 표준은 Organization for the Advancement of Structured Information Standards (`OASIS`) 컨소시엄의 기술 위원회에서 개발 및 유지 관리합니다. `OpenOffice.org`와 `LibreOffice`의 기본 형식인 OpenOffice.org XML에 대한 Sun Microsystems 사양을 기반으로 합니다. 원래 `StarOffice`를 위해 "오피스 문서에 대한 개방형 표준을 제공하기 위해" 개발되었습니다.

`UnstructuredODTLoader`는 `Open Office ODT` 파일을 로드하는 데 사용됩니다.

```python
from langchain_community.document_loaders import UnstructuredODTLoader

loader = UnstructuredODTLoader("example_data/fake.odt", mode="elements")
docs = loader.load()
docs[0]
```

```output
Document(page_content='Lorem ipsum dolor sit amet.', metadata={'source': 'example_data/fake.odt', 'category_depth': 0, 'file_directory': 'example_data', 'filename': 'fake.odt', 'last_modified': '2023-12-19T13:42:18', 'languages': ['por', 'cat'], 'filetype': 'application/vnd.oasis.opendocument.text', 'category': 'Title'})
```
