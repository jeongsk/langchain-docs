title: YoutubeLoaderDL
---

`yt-dlp` 라이브러리를 활용하는 Youtube용 로더입니다.

이 패키지는 Youtube용 [문서 로더](/oss/integrations/document_loaders/)를 구현합니다. `pytube`에 의존하는 `langchain-community`의 [YoutubeLoader](https://python.langchain.com/api_reference/community/document_loaders/langchain_community.document_loaders.youtube.YoutubeLoader.html)와 달리, `YoutubeLoaderDL`은 YouTube 메타데이터를 가져올 수 있습니다. `langchain-yt-dlp`는 강력한 `yt-dlp` 라이브러리를 활용하여 보다 안정적이고 기능이 풍부한 YouTube 문서 로더를 제공합니다.

## 개요

### 통합 세부 정보

| 클래스 | 패키지 | 로컬 | 직렬화 가능 | JS 지원 |
| :--- | :--- | :---: | :---: | :---: |
| YoutubeLoader | langchain-yt-dlp | ✅ | ✅ | ❌ |

## 설정

### 설치

```bash
pip install langchain-yt-dlp
```

### 초기화

```python
from langchain_yt_dlp.youtube_loader import YoutubeLoaderDL

# 기본 트랜스크립트 로딩
loader = YoutubeLoaderDL.from_youtube_url(
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ", add_video_info=True
)
```

### 로드

```python
documents = loader.load()
```

documents[0].metadata
