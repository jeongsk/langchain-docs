# 샘플 Markdown 문서

## 소개

이 샘플 Markdown 문서에 오신 것을 환영합니다. Markdown은 텍스트 서식을 지정하는 데 사용되는 경량 마크업 언어입니다. 문서화, readme 파일 등에 널리 사용됩니다.

## 기능

### 헤더

Markdown은 여러 수준의 헤더를 지원합니다:

- **Header 1**: `# Header 1`
- **Header 2**: `## Header 2`
- **Header 3**: `### Header 3`

### 리스트

#### 순서 없는 리스트

- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2

#### 순서 있는 리스트

1. First item
2. Second item
3. Third item
