LangChain 문서를 최대한 접근 가능하도록 만들고자 합니다. AI 어시스턴트, 코드 에디터, 그리고 Model Context Protocol(MCP)과 같은 직접 통합을 통해 프로그래밍 방식으로 문서를 활용할 수 있는 여러 가지 방법을 제공하고 있습니다.

## MCP 서버 사용하기

LangChain 문서에는 AI 애플리케이션이 최신 문서를 실시간으로 조회할 수 있도록 해주는 **Model Context Protocol(MCP) 서버**가 내장되어 있습니다.

LangChain 문서 MCP 서버는 다음 주소에서 이용 가능합니다:

```txt
https://docs.langchain.com/mcp
```

연결이 완료되면 AI 어시스턴트에게 LangChain, LangGraph, LangSmith에 관한 질문을 할 수 있으며, 어시스턴트는 문서를 검색하여 정확하고 최신의 답변을 제공할 것입니다.

### Claude Code와 연결하기

Claude Code를 사용하고 계신다면, 터미널에서 다음 명령어를 실행하여 현재 프로젝트에 서버를 추가하세요:

```bash
claude mcp add --transport http docs-langchain https://docs.langchain.com/mcp
```

<Note>
    **프로젝트(로컬) 범위 적용**

    위 명령어는 현재 프로젝트/작업 디렉토리에만 MCP 서버를 추가합니다. MCP 서버를 전역적으로 추가하여 모든 프로젝트에서 액세스하려면 명령어에 `--scope user`를 추가하여 사용자 범위를 설정하세요:

    ```bash
    claude mcp add --transport http docs-langchain --scope user https://docs.langchain.com/mcp
    ```
</Note>

### Claude Desktop과 연결하기

1. Claude Desktop을 여세요
2. 설정 > 커넥터로 이동하세요
3. MCP 서버 URL을 추가하세요: `https://docs.langchain.com/mcp`

### Cursor 또는 VS Code와 연결하기

MCP 설정 구성 파일에 다음 내용을 추가하세요:

```json
{
  "mcpServers": {
    "docs-langchain": {
      "url": "https://docs.langchain.com/mcp"
    }
  }
}
```
