프롬프트는 대규모 언어 모델(LLM)의 동작을 안내합니다. [_프롬프트 엔지니어링_](/langsmith/prompt-engineering-concepts)은 LLM이 신뢰할 수 있고 유용한 응답을 생성하도록 제공하는 지침을 작성하고, 테스트하며, 개선하는 과정입니다.

LangSmith는 프롬프트를 생성하고, 버전 관리하며, 테스트하고, 협업할 수 있는 도구를 제공합니다. [_프롬프트 템플릿_](/langsmith/prompt-engineering-concepts#prompts-vs-prompt-templates)과 같은 일반적인 개념도 접하게 되는데, 이를 통해 구조화된 프롬프트를 재사용할 수 있으며, [_변수_](/langsmith/prompt-engineering-concepts#f-string-vs-mustache)를 사용하면 프롬프트에 값(예: 사용자의 질문)을 동적으로 삽입할 수 있습니다.

이 빠른 시작에서는 UI 또는 SDK를 사용하여 프롬프트를 생성하고, 테스트하며, 개선합니다. 이 빠른 시작은 OpenAI를 예제 LLM 공급자로 사용하지만, 동일한 워크플로우가 다른 공급자에도 적용됩니다.

<Tip>
프롬프트 엔지니어링 시작에 대한 비디오를 선호하는 경우 빠른 시작 [비디오 가이드](#video-guide)를 참조하세요.
</Tip>

## 사전 준비사항

시작하기 전에 다음 사항이 있는지 확인하세요:

- **LangSmith 계정**: [smith.langchain.com](https://smith.langchain.com)에서 가입하거나 로그인하세요.
- **LangSmith API 키**: [API 키 생성](/langsmith/create-account-api-key#create-an-api-key) 가이드를 따르세요.
- **OpenAI API 키**: [OpenAI 대시보드](https://platform.openai.com/account/api-keys)에서 생성하세요.

## 4. 프롬프트 반복

LangSmith는 팀 기반 프롬프트 반복을 허용합니다. [워크스페이스](/langsmith/administration-overview#workspaces) 구성원은 플레이그라운드에서 프롬프트를 실험하고 준비가 되면 변경 사항을 새로운 [_커밋_](/langsmith/prompt-engineering-concepts#commits)으로 저장할 수 있습니다.

프롬프트를 개선하려면:

- 다음과 같은 모델 공급자가 제공하는 프롬프트 생성 모범 사례 문서를 참조하세요:
    - [OpenAI API를 사용한 프롬프트 엔지니어링 모범 사례](https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-the-openai-api)
    - [Gemini의 프롬프트 디자인 소개](https://ai.google.dev/gemini-api/docs/prompting-intro)
- LangSmith의 대화형 도구인 Prompt Canvas로 프롬프트를 구축하고 개선하세요. [Prompt Canvas 가이드](/langsmith/write-prompt-with-ai)에서 자세히 알아보세요.
- 커밋 기록에서 중요한 순간을 표시하기 위해 특정 커밋에 태그를 지정하세요.
    1. 커밋을 생성하려면 **Playground**로 이동하여 **Commit**을 선택합니다. 변경 사항을 커밋할 프롬프트를 선택한 다음 **Commit**을 클릭합니다.
    1. 왼쪽 메뉴의 **Prompts**로 이동합니다. 프롬프트를 선택합니다. 프롬프트의 상세 페이지에서 **Commits** 탭으로 이동합니다. 태그 아이콘 <Icon icon="tag" iconType="solid" />을 찾아 **Add a Commit Tag**를 클릭합니다.

## 2. 프롬프트 생성

프롬프트를 생성하려면 프롬프트에 포함하려는 메시지 목록을 정의한 다음 LangSmith로 푸시합니다.

언어별 생성자와 푸시 메서드를 사용합니다:

- Python: [`ChatPromptTemplate`](https://python.langchain.com/api_reference/core/prompts/langchain_core.prompts.chat.ChatPromptTemplate.html) → [`client.push_prompt(...)`](https://docs.smith.langchain.com/reference/python/client/langsmith.client.Client#langsmith.client.Client.push_prompt)
- TypeScript: [`ChatPromptTemplate.fromMessages(...)`](https://v03.api.js.langchain.com/classes/_langchain_core.prompts.ChatPromptTemplate.html#fromMessages) → [`client.pushPrompt(...)`](https://langsmith-docs-7jgx2bq8f-langchain.vercel.app/reference/js/classes/client.Client#pushprompt)

1. `create_prompt` 파일에 다음 코드를 추가합니다:

    <CodeGroup>

    ```python Python
    from langsmith import Client
    from langchain_core.prompts import ChatPromptTemplate

    client = Client()

    prompt = ChatPromptTemplate([
        ("system", "You are a helpful chatbot."),
        ("user", "{question}"),
    ])

    client.push_prompt("prompt-quickstart", object=prompt)
    ```

    ```typescript TypeScript
    import { Client } from "langsmith";
    import { ChatPromptTemplate } from "@langchain/core/prompts";

    const client = new Client();

    const prompt = ChatPromptTemplate.fromMessages([
    ["system", "You are a helpful chatbot."],
    ["user", "{question}"],
    ]);

    await client.pushPrompt("prompt-quickstart", {
    object: prompt,
    });
    ```

    </CodeGroup>

    이것은 메시지의 순서가 있는 목록을 생성하고, `ChatPromptTemplate`으로 래핑한 다음, 버전 관리 및 재사용을 위해 프롬프트를 이름으로 [워크스페이스](/langsmith/administration-overview#workspaces)에 푸시합니다.

1. `create_prompt`를 실행합니다:

    <CodeGroup>

    ```python Python
    python create_prompt.py
    ```

    ```typescript TypeScript
    npx tsx create_prompt.ts
    ```

    </CodeGroup>

결과 링크를 따라 LangSmith UI에서 새로 생성된 Prompt Hub 프롬프트를 확인합니다.

## 3. 프롬프트 테스트

이 단계에서는 [2단계](#2-create-a-prompt)에서 생성한 프롬프트를 이름(`"prompt-quickstart"`)으로 가져오고, 테스트 입력으로 포맷하며, OpenAI의 채팅 형식으로 변환한 다음, OpenAI Chat Completions API를 호출합니다.

그런 다음 새 버전을 생성하여 프롬프트를 반복합니다. 워크스페이스의 구성원은 기존 프롬프트를 열고, [UI](https://smith.langchain.com)에서 변경 사항을 실험하며, 해당 변경 사항을 동일한 프롬프트의 새 커밋으로 저장할 수 있습니다. 이렇게 하면 전체 팀의 기록이 보존됩니다.

1. `test_prompt` 파일에 다음을 추가합니다:

    <CodeGroup>

    ```python Python
    from langsmith import Client
    from openai import OpenAI
    from langchain_core.messages import convert_to_openai_messages

    client = Client()
    oai_client = OpenAI()

    prompt = client.pull_prompt("prompt-quickstart")

    # Since the prompt only has one variable you could also pass in the value directly
    # Equivalent to formatted_prompt = prompt.invoke("What is the color of the sky?")
    formatted_prompt = prompt.invoke({"question": "What is the color of the sky?"})

    response = oai_client.chat.completions.create(
        model="gpt-4o",
        messages=convert_to_openai_messages(formatted_prompt.messages),
    )
    ```

    ```typescript TypeScript
    import { OpenAI } from "openai";
    import { pull } from "langchain/hub"
    import { convertPromptToOpenAI } from "@langchain/openai";

    const oaiClient = new OpenAI();

    const prompt = await pull("prompt-quickstart");

    // Format the prompt with the question
    const formattedPrompt = await prompt.invoke({ question: "What is the color of the sky?" });

    const response = await oaiClient.chat.completions.create({
        model: "gpt-4o",
        messages: convertPromptToOpenAI(formattedPrompt).messages,
    });
    ```
    </CodeGroup>

    이것은 테스트 중인 프롬프트의 최신 커밋 버전에 대해 `pull`을 사용하여 이름으로 프롬프트를 로드합니다. 커밋 해시 `"<prompt-name>:<commit-hash>"`를 전달하여 특정 커밋을 지정할 수도 있습니다.

1. `test_prompt`를 실행합니다:

    <CodeGroup>

    ```python Python
    python test_prompt.py
    ```

    ```typescript TypeScript
    npx tsx test_prompt.ts
    ```

    </CodeGroup>

1. 프롬프트의 새 버전을 생성하려면 처음 사용했던 것과 동일한 푸시 메서드를 동일한 프롬프트 이름과 업데이트된 템플릿으로 호출합니다. LangSmith는 이를 새 커밋으로 기록하고 이전 버전을 보존합니다.

    다음 코드를 `iterate_prompt` 파일에 복사합니다:

    <CodeGroup>

    ```python Python
    from langsmith import Client
    from langchain_core.prompts import ChatPromptTemplate

    client = Client()

    new_prompt = ChatPromptTemplate([
        ("system", "You are a helpful chatbot. Respond in Spanish."),
        ("user", "{question}"),
    ])

    client.push_prompt("prompt-quickstart", object=new_prompt)
    ```

    ```typescript TypeScript
    import { Client } from "langsmith";
    import { ChatPromptTemplate } from "@langchain/core/prompts";

    const client = new Client();

    const newPrompt = ChatPromptTemplate.fromMessages([
        ["system", "You are a helpful chatbot. Speak in Spanish."],
        ["user", "{question}"]
    ]);

    await client.pushPrompt("prompt-quickstart", {
        object: newPrompt
    });
    ```

    </CodeGroup>

1. `iterate_prompt`를 실행합니다:

    <CodeGroup>

    ```python Python
    python iterate_prompt.py
    ```

    ```typescript TypeScript
    npx tsx iterate_prompt.ts
    ```
    </CodeGroup>

    이제 프롬프트에 두 개의 커밋이 포함됩니다.

프롬프트를 개선하려면:

- 다음과 같은 모델 공급자가 제공하는 프롬프트 생성 모범 사례 문서를 참조하세요:
    - [OpenAI API를 사용한 프롬프트 엔지니어링 모범 사례](https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-the-openai-api)
    - [Gemini의 프롬프트 디자인 소개](https://ai.google.dev/gemini-api/docs/prompting-intro)
- LangSmith의 대화형 도구인 Prompt Canvas로 프롬프트를 구축하고 개선하세요. [Prompt Canvas 가이드](/langsmith/write-prompt-with-ai)에서 자세히 알아보세요.
