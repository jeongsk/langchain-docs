**LangGraph Server**는 에이전트 기반 애플리케이션을 생성하고 관리하기 위한 API를 제공합니다. 이는 특정 작업을 위해 구성된 에이전트인 [어시스턴트](/langsmith/assistants) 개념을 기반으로 구축되었으며, 내장된 [영속성](/oss/langgraph/persistence#memory-store)과 **태스크 큐**를 포함합니다. 이 다목적 API는 백그라운드 처리부터 실시간 상호작용까지 광범위한 에이전틱 애플리케이션 사용 사례를 지원합니다.

LangGraph Server를 사용하여 [어시스턴트](/langsmith/assistants), [스레드](/oss/langgraph/persistence#threads), [실행](/langsmith/assistants#execution), [크론 작업](/langsmith/cron-jobs), [웹훅](/langsmith/use-webhooks) 등을 생성하고 관리할 수 있습니다.

<Tip>
**API 참조**<br></br>
API 엔드포인트 및 데이터 모델에 대한 자세한 정보는 [API 참조 문서](https://langchain-ai.github.io/langgraph/cloud/reference/api/api_ref.html)를 참조하세요.
</Tip>

LangGraph Server의 `Enterprise` 버전을 사용하려면 Docker 이미지를 실행할 때 지정해야 하는 라이선스 키를 획득해야 합니다. 라이선스 키를 획득하려면 [영업팀에 문의](https://www.langchain.com/contact-sales)하세요.

다음 LangSmith [호스팅](/langsmith/hosting) 옵션에서 LangGraph Server의 `Enterprise` 버전을 실행할 수 있습니다:

- [클라우드](/langsmith/cloud)
- [하이브리드](/langsmith/hybrid)
- [자체 호스팅](/langsmith/self-hosted)

## 애플리케이션 구조

LangGraph Server 애플리케이션을 배포하려면 배포하려는 그래프와 의존성 및 환경 변수와 같은 관련 구성 설정을 지정해야 합니다.

배포를 위해 LangGraph 애플리케이션을 구조화하는 방법을 알아보려면 [애플리케이션 구조](/langsmith/application-structure) 가이드를 읽어보세요.

## 배포의 구성 요소

LangGraph Server를 배포할 때는 하나 이상의 [그래프](#graphs), [영속성](/oss/langgraph/persistence)을 위한 데이터베이스, 그리고 태스크 큐를 배포하게 됩니다.

### 그래프

LangGraph Server로 그래프를 배포할 때는 [어시스턴트](/langsmith/assistants)의 "청사진"을 배포하는 것입니다.

[어시스턴트](/langsmith/assistants)는 특정 구성 설정과 쌍을 이루는 그래프입니다. 그래프당 여러 어시스턴트를 생성할 수 있으며, 각 어시스턴트는 동일한 그래프로 제공할 수 있는 다양한 사용 사례를 수용하기 위한 고유한 설정을 가질 수 있습니다.

배포 시 LangGraph Server는 그래프의 기본 구성 설정을 사용하여 각 그래프에 대한 기본 어시스턴트를 자동으로 생성합니다.

<Note>
우리는 종종 그래프를 [에이전트](/oss/langgraph/workflows-agents)를 구현하는 것으로 생각하지만, 그래프가 반드시 에이전트를 구현해야 하는 것은 아닙니다. 예를 들어, 그래프는 애플리케이션 제어 흐름에 영향을 줄 수 있는 능력 없이 양방향 대화만 지원하는 간단한 챗봇을 구현할 수 있습니다. 실제로 애플리케이션이 더 복잡해지면서 그래프는 종종 [여러 에이전트](/oss/langchain/multi-agent)가 함께 작동하는 더 복잡한 흐름을 구현하게 됩니다.
</Note>

### 영속성 및 태스크 큐

LangGraph Server는 [영속성](/oss/langgraph/persistence)을 위한 데이터베이스와 태스크 큐를 활용합니다.

LangGraph Server의 데이터베이스로는 [PostgreSQL](https://www.postgresql.org/)이 지원되며, 태스크 큐로는 [Redis](https://redis.io/)가 지원됩니다.

[LangSmith 클라우드](/langsmith/cloud)를 사용하여 배포하는 경우 이러한 구성 요소는 자동으로 관리됩니다. [자체 인프라](/langsmith/self-hosted)에 LangGraph Server를 배포하는 경우에는 이러한 구성 요소를 직접 설정하고 관리해야 합니다.

이러한 구성 요소가 어떻게 설정되고 관리되는지에 대한 자세한 정보는 [호스팅 옵션](/langsmith/hosting) 가이드를 검토하세요.
