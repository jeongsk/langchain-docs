[LangSmith Deployments UI](https://smith.langchain.com)의 [Studio](/langsmith/studio)는 두 가지 유형의 그래프에 연결할 수 있습니다:

- [클라우드 또는 자체 호스팅](#deployed-graphs)으로 배포된 그래프
- [LangGraph 서버](#local-development-server)를 통해 로컬에서 실행되는 그래프

## 배포된 그래프

Studio는 [LangSmith UI](https://smith.langchain.com)의 **Deployments** 메뉴에서 접근할 수 있습니다.

[배포된](/langsmith/deployment-quickstart) 애플리케이션의 경우, 해당 배포의 일부로 Studio에 접근할 수 있습니다. 이를 위해 UI에서 배포로 이동한 후 **Studio**를 선택하세요.

그러면 라이브 배포에 연결된 Studio가 로드되며, 해당 배포의 [스레드](/oss/langgraph/persistence#threads), [어시스턴트](/langsmith/assistants), [메모리](/oss/concepts/memory)를 생성, 조회, 업데이트할 수 있습니다.

## 로컬 개발 서버

### 사전 요구 사항

Studio를 사용하여 로컬에서 애플리케이션을 테스트하려면:

- 먼저 [로컬 애플리케이션 빠른 시작](/langsmith/local-server)을 진행하세요.
- LangSmith로 데이터를 [추적](/langsmith/observability-concepts#traces)하고 싶지 않다면, 애플리케이션의 `.env` 파일에 `LANGSMITH_TRACING=false`를 설정하세요. 추적을 비활성화하면 로컬 서버에서 어떤 데이터도 외부로 전송되지 않습니다.

### 설정

1. [LangGraph CLI](/langsmith/cli)를 설치하세요:

    <CodeGroup>
    ```bash pip
    pip install -U "langgraph-cli[inmem]"
    langgraph dev
    ```

    ```bash uv
    uv add langgraph-cli[inmem]
    langgraph dev
    ```

    ```bash npm
    npx @langchain/langgraph-cli dev
    ```
    </CodeGroup>

    <Warning>
    **브라우저 호환성**
    Safari는 Studio로의 `localhost` 연결을 차단합니다. 이 문제를 해결하려면 `--tunnel` 옵션과 함께 명령을 실행하여 보안 터널을 통해 Studio에 접근하세요.
    </Warning>

    이 명령은 LangGraph 서버를 로컬에서 인메모리 방식으로 시작합니다. 서버는 워치 모드로 실행되며, 코드 변경을 감지하여 자동으로 재시작됩니다. API 서버 시작을 위한 모든 옵션에 대해서는 이 [레퍼런스](/langsmith/cli#dev)를 참조하세요.

    다음과 같은 로그가 표시됩니다:

    ```
    > Ready!
    >
    > - API: [http://localhost:2024](http://localhost:2024/)
    >
    > - Docs: http://localhost:2024/docs
    >
    > - LangSmith Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
    ```

    실행되면 자동으로 Studio로 이동합니다.

1. 실행 중인 서버의 경우 다음 방법 중 하나로 디버거에 접근하세요:
    1. 다음 URL로 직접 이동: `https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024`.
    1. UI의 **Deployments**로 이동하여 배포의 **Studio** 버튼을 클릭하고, `http://127.0.0.1:2024`를 입력한 후 **Connect**를 클릭하세요.

    서버를 다른 호스트나 포트에서 실행하는 경우, `baseUrl`을 그에 맞게 업데이트하세요.

### (선택사항) 디버거 연결

브레이크포인트와 변수 검사를 사용한 단계별 디버깅을 위해 다음을 실행하세요:

    <CodeGroup>
    ```bash pip
    # debugpy 패키지 설치
    pip install debugpy
    # 디버깅을 활성화하여 서버 시작
    langgraph dev --debug-port 5678
    ```

    ```bash uv
    # debugpy 패키지 설치
    uv add debugpy
    # 디버깅을 활성화하여 서버 시작
    langgraph dev --debug-port 5678
    ```
    </CodeGroup>

그런 다음 선호하는 디버거를 연결하세요:

<Tabs>
    <Tab title="VS Code">
    `launch.json`에 다음 구성을 추가하세요:

    ```json
    {
        "name": "Attach to LangGraph",
        "type": "debugpy",
        "request": "attach",
        "connect": {
          "host": "0.0.0.0",
          "port": 5678
        }
    }
    ```
    </Tab>
    <Tab title="PyCharm">
    1. Run → Edit Configurations로 이동
    2. +를 클릭하고 "Python Debug Server" 선택
    3. IDE host name을 `localhost`로 설정
    4. 포트를 `5678`로 설정 (또는 이전 단계에서 선택한 포트 번호)
    5. "OK"를 클릭하고 디버깅 시작
    </Tab>
</Tabs>

<Tip>
시작하는 데 문제가 있다면 [문제 해결 가이드](/langsmith/troubleshooting-studio)를 참조하세요.
</Tip>
