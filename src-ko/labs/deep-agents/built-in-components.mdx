Deep Agents는 에이전트가 복잡한 작업을 수행하는 데 도움이 되는 여러 내장 컴포넌트를 제공합니다.

## 시스템 프롬프트

Deep Agents는 Claude Code의 아키텍처에서 크게 영감을 받은 상세한 시스템 프롬프트를 제공합니다. 이 프롬프트는 계획 도구, 파일 시스템 도구, 서브 에이전트를 효과적으로 사용하기 위한 지침을 제공합니다.

## 계획 도구

Claude Code의 TodoWrite 기능을 기반으로 한 간단한 계획 도구로, 에이전트가 컨텍스트 내에서 계획을 생성하고 추적하여 복잡한 작업을 수행하는 동안 방향을 유지할 수 있도록 도와줍니다.

## 파일 시스템 도구

LangGraph의 상태를 사용하여 파일 시스템을 모킹하는 네 가지 내장 도구:

- `ls` - 파일 및 디렉토리 목록 조회
- `read_file` - 파일 내용 읽기
- `write_file` - 파일에 쓰기
- `edit_file` - 기존 파일 편집

파일은 files 키를 통해 전달하고 조회할 수 있습니다:

<CodeGroup>

```python Python
# 에이전트에 파일 전달
result = agent.invoke({
    "messages": [...],
    "files": {"foo.txt": "file content", ...}
})

# 실행 후 파일 접근
updated_files = result["files"]
```

```typescript JavaScript
const result = await agent.invoke({
  messages: [...],
  // 이 키를 사용하여 에이전트에 파일 전달
  files: {"foo.txt": "foo", ...}
});

// 이후 파일에 이렇게 접근
result.files;
```

</CodeGroup>

## 서브 에이전트

다음 기능을 갖춘 특화된 서브 에이전트 호출을 위한 내장 지원:

- **컨텍스트 격리**: 메인 에이전트의 컨텍스트 오염 방지
- **맞춤 지침**: 특정 작업을 위한 맞춤형 프롬프트
- **도구 접근 제어**: 서브 에이전트는 다른 도구 세트를 가질 수 있음

메인 에이전트와 동일한 지침 및 도구를 가진 범용 서브 에이전트가 항상 사용 가능합니다.

## MCP

`deepagents` 라이브러리는 MCP 도구와 함께 실행할 수 있습니다. 이는 [LangChain MCP Adapter 라이브러리](https://github.com/langchain-ai/langchain-mcp-adapters)를 사용하여 구현할 수 있습니다.

예시:

```python
# pip install langchain-mcp-adapters

import asyncio
from langchain_mcp_adapters.client import MultiServerMCPClient
from deepagents import create_deep_agent

async def main():
    # MCP 도구 수집
    mcp_client = MultiServerMCPClient(...)
    mcp_tools = await mcp_client.get_tools()

    # 에이전트 생성
    agent = create_deep_agent(tools=mcp_tools, ....)

    # 에이전트 스트리밍
    async for chunk in agent.astream(
        {"messages": [{"role": "user", "content": "what is langgraph?"}]},
        stream_mode="values"
    ):
        if "messages" in chunk:
            chunk["messages"][-1].pretty_print()

asyncio.run(main())
```
