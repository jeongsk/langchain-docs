title: "도구 및 툴킷"

[도구](/oss/langchain/tools)는 모델이 호출하도록 설계된 유틸리티입니다. 도구의 입력은 모델에 의해 생성되도록 설계되었으며, 출력은 다시 모델에 전달되도록 설계되었습니다.

툴킷은 함께 사용하도록 의도된 도구들의 모음입니다.

## 검색

| 도구/툴킷 | 무료/유료 | 반환 데이터 |
|-------------|-----------|-------------|
| [Bing Search](/oss/integrations/tools/bing_search) | 유료 | URL, 스니펫, 제목 |
| [Brave Search](/oss/integrations/tools/brave_search) | 무료 | URL, 스니펫, 제목 |
| [DuckDuckgoSearch](/oss/integrations/tools/ddg) | 무료 | URL, 스니펫, 제목 |
| [Exa Search](/oss/integrations/tools/exa_search) | 월 1000회 무료 검색 | URL, 작성자, 제목, 게시일 |
| [Google Search](/oss/integrations/tools/google_search) | 유료 | URL, 스니펫, 제목 |
| [Google Serper](/oss/integrations/tools/google_serper) | 무료 | URL, 스니펫, 제목, 검색 순위, 사이트 링크 |
| [Jina Search](/oss/integrations/tools/jina_search) | 응답 토큰 100만개 무료 | URL, 스니펫, 제목, 페이지 콘텐츠 |
