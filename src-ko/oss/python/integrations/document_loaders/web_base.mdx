이는 `WebBaseLoader`를 사용하여 `HTML` 웹 페이지의 모든 텍스트를 다운스트림에서 사용할 수 있는 문서 형식으로 로드하는 방법을 다룹니다. 웹 페이지 로드를 위한 더 많은 사용자 정의 로직을 보려면 `IMSDbLoader`, `AZLyricsLoader`, `CollegeConfidentialLoader`와 같은 하위 클래스 예제를 참조하세요.

웹 사이트 크롤링, JS 차단 사이트 우회 및 데이터 정리에 대해 걱정하고 싶지 않다면 `FireCrawlLoader` 또는 더 빠른 옵션인 `SpiderLoader`를 사용하는 것이 좋습니다.

## 설정

### 자격 증명

`WebBaseLoader`는 자격 증명이 필요하지 않습니다.

### 설치

`WebBaseLoader`를 사용하려면 먼저 `langchain-community` python 패키지를 설치해야 합니다.

```python
%pip install -qU langchain-community beautifulsoup4
```

## 초기화

이제 모델 객체를 인스턴스화하고 문서를 로드할 수 있습니다:

```python
from langchain_community.document_loaders import WebBaseLoader

loader = WebBaseLoader("https://www.example.com/")
```

가져오는 동안 SSL 확인 오류를 우회하려면 "verify" 옵션을 설정할 수 있습니다:

`loader.requests_kwargs = {'verify':False}`

### 여러 페이지로 초기화

로드할 페이지 목록을 전달할 수도 있습니다.

```python
loader_multiple_pages = WebBaseLoader(
    ["https://www.example.com/", "https://google.com"]
)
```

### 여러 URL 동시 로드

여러 URL을 동시에 스크래핑하고 파싱하여 스크래핑 프로세스의 속도를 높일 수 있습니다.

동시 요청에는 합리적인 제한이 있으며 기본값은 초당 2개입니다. 좋은 시민이 되는 것에 대해 걱정하지 않거나 스크래핑하는 서버를 제어하고 부하에 대해 신경 쓰지 않는다면 `requests_per_second` 매개변수를 변경하여 최대 동시 요청을 늘릴 수 있습니다. 이렇게 하면 스크래핑 프로세스의 속도가 빨라지지만 서버가 차단할 수 있습니다. 조심하세요!

```python
import nest_asyncio

nest_asyncio.apply()
```

### XML 파일 로드 또는 다른 BeautifulSoup 파서 사용

이 기능을 사용하는 예제는 sitemap 파일을 로드하는 방법의 예인 `SitemapLoader`를 참조할 수도 있습니다.

```python
loader = WebBaseLoader(
    "https://www.govinfo.gov/content/pkg/CFR-2018-title10-vol3/xml/CFR-2018-title10-vol3-sec431-86.xml"
)
loader.default_parser = "xml"
docs = loader.load()
docs
```

## 지연 로드

메모리 요구 사항을 최소화하기 위해 지연 로딩을 사용하여 한 번에 하나의 페이지만 로드할 수 있습니다.

```python
pages = []
for doc in loader.lazy_load():
    pages.append(doc)

print(pages[0].page_content[:100])
print(pages[0].metadata)
```

## 프록시 사용

때때로 IP 차단을 우회하기 위해 프록시를 사용해야 할 수 있습니다. 프록시 사전을 로더(및 하위 `requests`)에 전달하여 사용할 수 있습니다.

```python
loader = WebBaseLoader(
        "https://www.walmart.com/search?q=parrots",
        proxies={
        "http": "http://{username}:{password}:@proxy.service.com:6666/",
        "https": "https://{username}:{password}:@proxy.service.com:6666/",
    },
)
docs = loader.load()
```
