[Geopandas](https://geopandas.org/en/stable/index.html)는 Python에서 지리공간 데이터 작업을 더 쉽게 수행할 수 있도록 하는 오픈 소스 프로젝트입니다.

GeoPandas는 pandas에서 사용하는 데이터 타입을 확장하여 기하학적 타입에 대한 공간 연산을 가능하게 합니다.

기하학적 연산은 shapely에서 수행합니다. Geopandas는 파일 액세스를 위해 fiona에 의존하고 플로팅을 위해 matplotlib에 의존합니다.

지리공간 데이터를 활용하는 LLM 애플리케이션(채팅, QA)은 흥미로운 탐색 영역입니다.

```python
import ast

import geopandas as gpd
import pandas as pd
from langchain_community.document_loaders import OpenCityDataLoader
```

[`Open City Data`](/oss/integrations/document_loaders/open_city_data)에서 GeoPandas 데이터프레임을 예제 입력으로 생성합니다.

```python
# Open City Data 로드
dataset = "tmnf-yvry"  # San Francisco 범죄 데이터
loader = OpenCityDataLoader(city_id="data.sfgov.org", dataset_id=dataset, limit=5000)
docs = loader.load()
```

```python
# 사전 목록을 DataFrame으로 변환
df = pd.DataFrame([ast.literal_eval(d.page_content) for d in docs])

# 위도와 경도 추출
df["Latitude"] = df["location"].apply(lambda loc: loc["coordinates"][1])
df["Longitude"] = df["location"].apply(lambda loc: loc["coordinates"][0])

# geopandas DF 생성
gdf = gpd.GeoDataFrame(
    df, geometry=gpd.points_from_xy(df.Longitude, df.Latitude), crs="EPSG:4326"
)

# San Francisco의 유효한 경도와 위도만 유지
gdf = gdf[
    (gdf["Longitude"] >= -123.173825)
    & (gdf["Longitude"] <= -122.281780)
    & (gdf["Latitude"] >= 37.623983)
    & (gdf["Latitude"] <= 37.929824)
]
```

SF 범죄 데이터 샘플의 시각화입니다.

```python
import matplotlib.pyplot as plt

# San Francisco 지도 데이터 로드
sf = gpd.read_file("https://data.sfgov.org/resource/3psu-pn9h.geojson")

# San Francisco 지도와 포인트 플롯
fig, ax = plt.subplots(figsize=(10, 10))
sf.plot(ax=ax, color="white", edgecolor="black")
gdf.plot(ax=ax, color="red", markersize=5)
plt.show()
```

다운스트림 처리(임베딩, 채팅 등)를 위해 GeoPandas 데이터프레임을 @[`Document`]로 로드합니다.

`geometry`가 기본 `page_content` 열이 되고, 다른 모든 열은 `metadata`에 배치됩니다.

그러나 `page_content_column`을 지정할 수 있습니다.

```python
from langchain_community.document_loaders import GeoDataFrameLoader

loader = GeoDataFrameLoader(data_frame=gdf, page_content_column="geometry")
docs = loader.load()
```
