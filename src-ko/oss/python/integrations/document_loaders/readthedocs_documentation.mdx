>[Read the Docs](https://readthedocs.org/)는 오픈 소스 무료 소프트웨어 문서 호스팅 플랫폼입니다. `Sphinx` 문서 생성기로 작성된 문서를 생성합니다.

이 노트북은 `Read-The-Docs` 빌드의 일부로 생성된 HTML에서 콘텐츠를 로드하는 방법을 다룹니다.

실제 사용 예제는 [여기](https://github.com/langchain-ai/chat-langchain)를 참조하세요.

이는 HTML이 이미 폴더로 스크래핑되었다고 가정합니다. 다음 명령의 주석을 해제하고 실행하여 이 작업을 수행할 수 있습니다
