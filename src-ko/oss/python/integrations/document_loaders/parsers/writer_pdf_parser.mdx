이 가이드는 WRITER `PDFParser` [문서 로더](/oss/integrations/document_loaders/) 시작하기에 대한 간략한 개요를 제공합니다.

WRITER의 [PDF Parser](https://dev.writer.com/api-guides/api-reference/tool-api/pdf-parser#parse-pdf)는 PDF 문서를 텍스트나 Markdown과 같은 다른 형식으로 변환합니다. 이는 추가 분석이나 워크플로우 통합을 위해 PDF 파일에서 텍스트 콘텐츠를 추출하고 처리해야 할 때 특히 유용합니다. `langchain-writer`에서는 WRITER의 PDF Parser를 LangChain 문서 파서로 사용할 수 있도록 제공합니다.

## 설정

`PDFParser`는 `langchain-writer` 패키지에서 사용할 수 있습니다:

```python
%pip install --quiet -U langchain-writer
```

### 자격 증명

[WRITER AI Studio](https://app.writer.com/aistudio/signup?utm_campaign=devrel)에 가입하여 API 키를 생성하세요([Quickstart](https://dev.writer.com/api-guides/quickstart) 참조). 그런 다음 WRITER_API_KEY 환경 변수를 설정합니다:

```python
import getpass
import os

if not os.getenv("WRITER_API_KEY"):
    os.environ["WRITER_API_KEY"] = getpass.getpass("Enter your WRITER API key: ")
```

최고 수준의 관찰 가능성을 위해 [LangSmith](https://smith.langchain.com/)를 설정하는 것도 도움이 됩니다(필수는 아님). 설정하려면 `LANGSMITH_TRACING` 및 `LANGSMITH_API_KEY` 환경 변수를 설정할 수 있습니다:

```python
# os.environ["LANGSMITH_TRACING"] = "true"
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass()
```

### 인스턴스화

다음으로 원하는 출력 형식으로 WRITER PDF Parser 인스턴스를 생성합니다:

```python
from langchain_writer.pdf_parser import PDFParser

parser = PDFParser(format="markdown")
```

## 사용법

PDF Parser를 사용하는 방법에는 동기식과 비동기식 두 가지가 있습니다. 어느 경우든 PDF Parser는 @[`Document`] 객체 목록을 반환하며, 각 객체는 PDF 파일의 페이지에서 파싱된 콘텐츠를 포함합니다.

### 동기식 사용

PDF Parser를 동기식으로 호출하려면 파싱하려는 PDF 파일을 참조하는 `Blob` 객체를 `parse` 메서드에 전달합니다:

```python
from langchain_core.documents.base import Blob

file = Blob.from_path("../example_data/layout-parser-paper.pdf")

parsed_pages = parser.parse(blob=file)
parsed_pages
```

### 비동기식 사용

PDF Parser를 비동기식으로 호출하려면 파싱하려는 PDF 파일을 참조하는 `Blob` 객체를 `aparse` 메서드에 전달합니다:

```python
parsed_pages_async = await parser.aparse(blob=file)
parsed_pages_async
```
