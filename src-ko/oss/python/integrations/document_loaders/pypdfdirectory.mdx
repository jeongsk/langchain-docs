이제 모델 객체를 인스턴스화하고 문서를 로드할 수 있습니다:

```python
directory_path = (
    "../../docs/integrations/document_loaders/example_data/layout-parser-paper.pdf"
)
loader = PyPDFDirectoryLoader("example_data/")
```
