LangChain 패키지를 설치하려면:

:::python
<CodeGroup>
    ```bash pip
    pip install -U langchain
    ```

    ```bash uv
    uv add langchain
    ```
</CodeGroup>
:::

:::js
    <CodeGroup>
    ```bash npm
    npm install langchain @langchain/core
    ```

    ```bash pnpm
    pnpm add langchain @langchain/core
    ```

    ```bash yarn
    yarn add langchain @langchain/core
    ```

    ```bash bun
    bun add langchain @langchain/core
    ```
    </CodeGroup>
:::

LangChain은 수백 개의 LLM과 수천 개의 다른 통합을 제공합니다. 이러한 통합은 독립적인 프로바이더 패키지로 제공됩니다. 예를 들어:

:::python
<CodeGroup>
    ```bash pip
    # OpenAI 통합 설치
    pip install -U langchain-openai

    # Anthropic 통합 설치
    pip install -U langchain-anthropic
    ```
    ```bash uv
    # OpenAI 통합 설치
    uv add langchain-openai

    # Anthropic 통합 설치
    uv add langchain-anthropic
    ```
</CodeGroup>

:::

:::js
<CodeGroup>
    ```bash npm
    # OpenAI 통합 설치
    npm install @langchain/openai
    # Anthropic 통합 설치
    npm install @langchain/anthropic
    ```

    ```bash pnpm
    # OpenAI 통합 설치
    pnpm install @langchain/openai
    # Anthropic 통합 설치
    pnpm install @langchain/anthropic
    ```

    ```bash yarn
    # OpenAI 통합 설치
    yarn add @langchain/openai
    # Anthropic 통합 설치
    yarn add @langchain/anthropic
    ```

    ```bash bun
    # OpenAI 통합 설치
    bun add @langchain/openai
    # Anthropic 통합 설치
    bun add @langchain/anthropic
    ```
</CodeGroup>
:::

<Tip>
사용 가능한 통합의 전체 목록은 [통합 탭](/oss/integrations/providers/overview)을 참조하세요.
</Tip>
