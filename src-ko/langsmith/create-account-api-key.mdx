LangSmith를 시작하려면 먼저 계정을 생성해야 합니다. [여기](https://smith.langchain.com)에서 무료 계정에 가입할 수 있습니다. Google, GitHub, 이메일을 통한 로그인을 지원합니다.

![Create account](/langsmith/images/create-account.png)

## API 키

LangSmith는 두 가지 유형의 API 키를 지원합니다: Service Keys와 Personal Access Tokens입니다. 두 유형의 토큰 모두 LangSmith API에 대한 요청을 인증하는 데 사용할 수 있지만, 사용 사례가 다릅니다.

Service Keys와 Personal Access Tokens 간의 차이점에 대한 자세한 내용은 [관리 개념](/langsmith/administration-overview)을 참조하세요.

## API 키 생성

LangSmith로 트레이스를 기록하고 평가를 실행하려면 요청을 인증하기 위한 API 키를 생성해야 합니다. API 키는 워크스페이스 집합 또는 전체 조직으로 범위를 지정할 수 있습니다.

두 유형의 API 키를 생성하려면 [설정 페이지](https://smith.langchain.com/settings)로 이동한 다음 **API Keys** 섹션까지 스크롤하세요. 서비스 키의 경우 조직 범위 키와 워크스페이스 범위 키 중에서 선택하세요. 키가 워크스페이스 범위인 경우 워크스페이스를 지정해야 합니다. Enterprise 사용자는 키에 특정 역할을 할당하여 권한을 조정할 수도 있습니다. 키의 만료 기간을 설정하세요. 키는 선택한 일수 후에 사용할 수 없게 되거나, 선택한 경우 만료되지 않습니다. 그런 다음 **Create API Key**를 클릭하세요.

<Note>
API 키는 한 번만 표시되므로 반드시 복사하여 안전한 장소에 보관하세요.
</Note>

![Create API key](/langsmith/images/create-api-key.png)

## SDK 구성

`LANGSMITH_API_KEY` 외에 다음 환경 변수를 설정할 수 있습니다.

이는 EU 인스턴스를 사용하는 경우에만 필요합니다.

`LANGSMITH_ENDPOINT=https://eu.api.smith.langchain.com`

이는 둘 이상의 워크스페이스로 범위가 지정된 키에만 필요합니다.

`LANGSMITH_WORKSPACE_ID=<Workspace ID>`
