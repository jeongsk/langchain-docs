
### 2. LangSmith에 배포하기

<Steps>
<Step title="LangSmith Deployments로 이동">
    [LangSmith](https://smith.langchain.com/)에 로그인합니다. 왼쪽 사이드바에서 **Deployments**를 선택합니다.
</Step>
<Step title="새 배포 생성">
    **+ New Deployment** 버튼을 클릭합니다. 필수 필드를 입력할 수 있는 패널이 열립니다.
</Step>
<Step title="저장소 연결">
    처음 사용하는 경우이거나 이전에 연결하지 않은 비공개 저장소를 추가하는 경우, **Add new account** 버튼을 클릭하고 안내에 따라 GitHub 계정을 연결합니다.
</Step>
<Step title="저장소 배포">
    애플리케이션의 저장소를 선택합니다. **Submit**을 클릭하여 배포합니다. 완료되는 데 약 15분이 소요될 수 있습니다. **Deployment details** 화면에서 상태를 확인할 수 있습니다.
</Step>
</Steps>

### 3. Studio에서 애플리케이션 테스트하기

애플리케이션이 배포되면:

1. 방금 생성한 배포를 선택하여 자세한 정보를 확인합니다.
2. 오른쪽 상단의 **Studio** 버튼을 클릭합니다. Studio가 열리면서 그래프가 표시됩니다.

### 4. 배포의 API URL 가져오기

1. LangGraph의 **Deployment details** 화면에서 **API URL**을 클릭하여 클립보드에 복사합니다.
2. `URL`을 클릭하여 클립보드에 복사합니다.

### 5. API 테스트하기

이제 API를 테스트할 수 있습니다:

<Tabs>
<Tab title="Python">
1. LangGraph Python을 설치합니다:
```shell
pip install langgraph-sdk
```
2. 에이전트에 메시지를 전송합니다:
```python
from langgraph_sdk import get_sync_client # or get_client for async

client = get_sync_client(url="your-deployment-url", api_key="your-langsmith-api-key")

for chunk in client.runs.stream(
    None,    # Threadless run
    "agent", # Name of agent. Defined in langgraph.json.
    input={
        "messages": [{
            "role": "human",
            "content": "What is LangGraph?",
        }],
    },
    stream_mode="updates",
):
    print(f"Receiving new event of type: {chunk.event}...")
    print(chunk.data)
    print("\n\n")
```
</Tab>


<Tab title="Rest API">
```bash
curl -s --request POST \
    --url <DEPLOYMENT_URL>/runs/stream \
    --header 'Content-Type: application/json' \
    --header "X-Api-Key: <LANGSMITH API KEY> \
    --data "{
        \"assistant_id\": \"agent\", `# Name of agent. Defined in langgraph.json.`
        \"input\": {
            \"messages\": [
                {
                    \"role\": \"human\",
                    \"content\": \"What is LangGraph?\"
                }
            ]
        },
        \"stream_mode\": \"updates\"
    }"
```
</Tab>
