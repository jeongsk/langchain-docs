기존 실험에 대한 평가는 현재 Python SDK에서만 지원됩니다.

이미 실험을 실행했고 추가적인 평가 지표를 추가하고자 한다면, 이전과 같이 `evaluate()` / `aevaluate()` 메서드를 사용하여 실험에 평가자를 적용할 수 있습니다. 대상 함수 대신 실험 이름 또는 ID를 전달하기만 하면 됩니다:

```python
from langsmith import evaluate

def always_half(inputs: dict, outputs: dict) -> float:
    return 0.5

experiment_name = "my-experiment:abc"  # Replace with an actual experiment name or ID

evaluate(experiment_name, evaluators=[always_half])
```
