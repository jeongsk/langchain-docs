챗봇과 같은 대화형 인터페이스를 갖춘 AI 애플리케이션은 사용자와의 여러 상호작용, 즉 대화 *턴*을 통해 작동합니다. 이러한 애플리케이션의 성능을 평가할 때는 [데이터셋 구축](/langsmith/evaluation-concepts#datasets)과 [평가자](/langsmith/evaluation-concepts#evaluators) 및 메트릭 정의와 같은 핵심 개념이 여전히 유용합니다. 하지만 앱과 사용자 간의 *시뮬레이션*을 실행한 다음, 동적으로 생성된 이 궤적을 평가하는 것도 유용할 수 있습니다.

이렇게 하는 것의 장점은 다음과 같습니다:

* 기존 궤적의 전체 데이터셋에 대한 평가보다 시작하기 쉬움
* 초기 쿼리부터 성공 또는 실패 해결까지의 엔드투엔드 커버리지
* 앱의 여러 반복에 걸친 반복적 동작이나 컨텍스트 손실을 감지할 수 있는 능력

단점은 평가 표면적을 여러 턴으로 확대하기 때문에, 데이터셋의 정적 입력에 대한 앱의 단일 출력을 평가하는 것보다 일관성이 떨어진다는 것입니다.

![](/langsmith/images/multi-turn-trace.png)

이 가이드에서는 오픈소스 [`openevals`](https://github.com/langchain-ai/openevals) 패키지를 사용하여 멀티턴 상호작용을 시뮬레이션하고 평가하는 방법을 설명합니다. 이 패키지에는 AI 앱 평가를 위한 사전 구축된 평가자와 기타 편리한 리소스가 포함되어 있습니다. 또한 OpenAI 모델을 사용하지만 다른 제공업체도 사용할 수 있습니다.

## 시뮬레이션 실행

시작하는 데 필요한 두 가지 주요 구성 요소가 있습니다:

* `app`: 애플리케이션 또는 이를 래핑하는 함수. 입력 인자로 단일 채팅 메시지(role 및 content 키가 있는 dict)를 받고 kwarg로 `thread_id`를 받아야 합니다. 향후 릴리스에서 더 많은 kwarg가 추가될 수 있으므로 다른 kwargs도 받아야 합니다. 최소한 role과 content 키가 있는 채팅 메시지를 출력으로 반환합니다.
* `user`: 시뮬레이션된 사용자. 이 가이드에서는 LLM을 사용하여 사용자 응답을 생성하는 `create_llm_simulated_user`라는 사전 구축된 함수를 사용하지만, [직접 만들 수도 있습니다](https://github.com/langchain-ai/openevals?tab=readme-ov-file#custom-simulated-users).

`openevals`의 시뮬레이터는 각 턴마다 `user`로부터 `app`으로 단일 채팅 메시지를 전달합니다. 따라서 필요한 경우 `thread_id`를 기반으로 현재 히스토리를 내부적으로 상태적으로 추적해야 합니다.

다음은 멀티턴 고객 지원 상호작용을 시뮬레이션하는 예시입니다. 이 가이드에서는 OpenAI 채팅 완성 API에 대한 단일 호출을 래핑하는 간단한 채팅 앱을 사용하지만, 여기에서 애플리케이션이나 에이전트를 호출하면 됩니다. 이 예시에서 시뮬레이션된 사용자는 특히 공격적인 고객의 역할을 합니다:

<CodeGroup>

```python Python
from openevals.simulators import run_multiturn_simulation, create_llm_simulated_user
from openevals.types import ChatCompletionMessage
from langsmith.wrappers import wrap_openai
from openai import OpenAI

# 추적을 위한 OpenAI 클라이언트 래핑
client = wrap_openai(OpenAI())
history = {}

# 애플리케이션 로직
def app(inputs: ChatCompletionMessage, *, thread_id: str, **kwargs):
    if thread_id not in history:
        history[thread_id] = []
    history[thread_id].append(inputs)
    # inputs는 role과 content가 있는 메시지 객체입니다
    res = client.chat.completions.create(
        model="gpt-4.1-mini",
        messages=[
            {
                "role": "system",
                "content": "You are a patient and understanding customer service agent.",
            },
        ] + history[thread_id],
    )
    response_message = res.choices[0].message
    history[thread_id].append(response_message)
    return response_message

user = create_llm_simulated_user(
    system="You are an aggressive and hostile customer who wants a refund for their car.",
    model="openai:gpt-4.1-mini",
)

# 새 함수로 시뮬레이션 직접 실행
simulator_result = run_multiturn_simulation(
    app=app,
    user=user,
    max_turns=5,
)
print(simulator_result)
```

```typescript TypeScript
  runMultiturnSimulation,

  history[threadId].push(inputs);
  const res = await client.chat.completions.create({
    model: "gpt-4.1-mini",
    messages: [
      {
        role: "system",
        content:
          "You are a patient and understanding customer service agent.",
      },
      inputs,
    ],
  });
  const responseMessage = res.choices[0].message;

};

const user = createLLMSimulatedUser({
  system: "You are an aggressive and hostile customer who wants a refund for their car.",
  model: "openai:gpt-4.1-mini",
});

const result = await runMultiturnSimulation({
  app,
  user,
  maxTurns: 5,
});
console.log(result);
```

## LangSmith 실험에서 실행

멀티턴 시뮬레이션의 결과를 LangSmith 실험의 일부로 사용하여 시간 경과에 따른 성능과 진행 상황을 추적할 수 있습니다. 이 섹션에서는 LangSmith의 [`pytest`](/langsmith/pytest)(Python 전용), [`Vitest`/`Jest`](/langsmith/vitest-jest)(JS 전용) 또는 [`evaluate`](/langsmith/evaluate-llm-application) 러너 중 하나 이상에 익숙하면 도움이 됩니다.

### `pytest` 또는 `Vitest/Jest` 사용

<Check>
테스트 프레임워크와의 LangSmith 통합을 사용하여 평가를 설정하는 방법을 알아보려면 다음 가이드를 참조하세요:

* [`pytest`](https://docs.smith.langchain.com/langsmith/pytest)
* [`Vitest` 또는 `Jest`](https://docs.smith.langchain.com/langsmith/vitest-jest)

</Check>

[LangSmith 테스트 프레임워크 통합](/langsmith/pytest) 중 하나를 사용하는 경우, 시뮬레이션을 실행할 때 `trajectory_evaluators` 파라미터로 OpenEvals 평가자 배열을 전달할 수 있습니다. 이러한 평가자는 시뮬레이션이 끝날 때 실행되며, 최종 채팅 메시지 목록을 `outputs` kwarg로 받습니다. 따라서 전달된 `trajectory_evaluator`는 이 kwarg를 받아야 합니다.

![](/langsmith/images/multi-turn-vitest.png)

다음은 예시입니다:

<CodeGroup>

```python Python
from openevals.simulators import run_multiturn_simulation, create_llm_simulated_user
from openevals.llm import create_llm_as_judge
from openevals.types import ChatCompletionMessage
from langsmith import testing as t
from langsmith.wrappers import wrap_openai
from openai import OpenAI
import pytest

@pytest.mark.langsmith
def test_multiturn_message_with_openai():
    inputs = {"role": "user", "content": "I want a refund for my car!"}
    t.log_inputs(inputs)
    # 추적을 위한 OpenAI 클라이언트 래핑
    client = wrap_openai(OpenAI())
    history = {}

    def app(inputs: ChatCompletionMessage, *, thread_id: str):
        if thread_id not in history:
            history[thread_id] = []
        history[thread_id] = history[thread_id] + [inputs]
        res = client.chat.completions.create(
            model="gpt-4.1-nano",
            messages=[
                {
                    "role": "system",
                    "content": "You are a patient and understanding customer service agent.",
                }
            ]
            + history[thread_id],
        )
        response = res.choices[0].message
        history[thread_id].append(response)
        return response

    user = create_llm_simulated_user(
        system="You are a nice customer who wants a refund for their car.",
        model="openai:gpt-4.1-nano",
        fixed_responses=[
            inputs,
        ],
    )
    trajectory_evaluator = create_llm_as_judge(
        model="openai:o3-mini",
        prompt="Based on the below conversation, was the user satisfied?\n{outputs}",
        feedback_key="satisfaction",
    )
    res = run_multiturn_simulation(
        app=app,
        user=user,
        trajectory_evaluators=[trajectory_evaluator],
        max_turns=5,
    )
    t.log_outputs(res)
    # 선택적으로, 평가자가 상호작용을 만족스러운 것으로 평가했는지 확인합니다.
    # "score"가 False이면 전체 테스트 케이스가 실패합니다.
    assert res["evaluator_results"][0]["score"]
```

```typescript TypeScript

import { wrapOpenAI } from "langsmith/wrappers/openai";

import { expect } from "vitest";

ls.describe("Multiturn demo", () => {
  ls.test(

      },

      const app = async (
        { inputs, threadId }: { inputs: ChatCompletionMessage, threadId: string }
      ) => {
        if (history[threadId] === undefined) {
          history[threadId] = [];
        }
        history[threadId].push(inputs);
        const res = await client.chat.completions.create({
          model: "gpt-4.1-nano",
          messages: [
            {
              role: "system",
              content:
                "You are a patient and understanding customer service agent",
            },
            inputs,
          ],
        });
        const responseMessage = res.choices[0].message;
        history[threadId].push(responseMessage);
        return responseMessage;
      };

      const user = createLLMSimulatedUser({
        system:
          "You are a nice customer who wants a refund for their car.",
        model: "openai:gpt-4.1-nano",
        fixedResponses: inputs.messages,
      });

      const trajectoryEvaluator = createLLMAsJudge({
        model: "openai:o3-mini",
        prompt:
          "Based on the below conversation, was the user satisfied?\n{outputs}",
        feedbackKey: "satisfaction",
      });

      const result = await runMultiturnSimulation({
        app,
        user,
        trajectoryEvaluators: [trajectoryEvaluator],
        maxTurns: 5,
      });

      ls.logOutputs(result);
      // 선택적으로, 평가자가 상호작용을 만족스러운 것으로 평가했는지 확인합니다.
      // "score"가 false이면 전체 테스트 케이스가 실패합니다.
      expect(result.evaluatorResults[0].score).toBe(true);
    }
  );
});
```

</CodeGroup>

LangSmith는 전달된 `trajectory_evaluators`에서 반환된 피드백을 자동으로 감지하고 기록하여 실험에 추가합니다. 또한 테스트 케이스는 시뮬레이션된 사용자의 `fixed_responses` 파라미터를 사용하여 특정 입력으로 대화를 시작하며, 이를 기록하고 저장된 데이터셋의 일부로 만들 수 있습니다.

시뮬레이션된 사용자의 시스템 프롬프트도 기록된 데이터셋의 일부로 포함하는 것이 편리할 수 있습니다.

### `evaluate` 사용

[`evaluate`](/langsmith/evaluate-llm-application) 러너를 사용하여 시뮬레이션된 멀티턴 상호작용을 평가할 수도 있습니다. 이는 다음과 같은 점에서 `pytest`/`Vitest`/`Jest` 예시와 약간 다릅니다:

* 시뮬레이션이 `target` 함수의 일부여야 하며, target 함수는 최종 궤적을 반환해야 합니다.
  * 이렇게 하면 궤적이 LangSmith가 평가자에게 전달할 `outputs`가 됩니다.
* `trajectory_evaluators` 파라미터를 사용하는 대신, 평가자를 `evaluate()` 메서드의 파라미터로 전달해야 합니다.
* 입력과 (선택적으로) 참조 궤적의 기존 데이터셋이 필요합니다.

다음은 예시입니다:

<CodeGroup>

```python Python
from openevals.simulators import run_multiturn_simulation, create_llm_simulated_user
from openevals.llm import create_llm_as_judge
from openevals.types import ChatCompletionMessage
from langsmith.wrappers import wrap_openai
from langsmith import Client
from openai import OpenAI

ls_client = Client()
examples = [
    {
        "inputs": {
            "messages": [{ "role": "user", "content": "I want a refund for my car!" }]
        },
    },
]
dataset = ls_client.create_dataset(dataset_name="multiturn-starter")
ls_client.create_examples(
    dataset_id=dataset.id,
    examples=examples,
)
trajectory_evaluator = create_llm_as_judge(
    model="openai:o3-mini",
    prompt="Based on the below conversation, was the user satisfied?\n{outputs}",
    feedback_key="satisfaction",
)

def target(inputs: dict):
    # 추적을 위한 OpenAI 클라이언트 래핑
    client = wrap_openai(OpenAI())
    history = {}

    def app(next_message: ChatCompletionMessage, *, thread_id: str):
        if thread_id not in history:
            history[thread_id] = []
        history[thread_id] = history[thread_id] + [next_message]
        res = client.chat.completions.create(
            model="gpt-4.1-nano",
            messages=[
                {
                    "role": "system",
                    "content": "You are a patient and understanding customer service agent.",
                }
            ]
            + history[thread_id],
        )
        response = res.choices[0].message
        history[thread_id].append(response)
        return response

    user = create_llm_simulated_user(
        system="You are a nice customer who wants a refund for their car.",
        model="openai:gpt-4.1-nano",
        fixed_responses=inputs["messages"],
    )
    res = run_multiturn_simulation(
        app=app,
        user=user,
        max_turns=5,
    )
    return res["trajectory"]

results = ls_client.evaluate(
    target,
    data=dataset.name,
    evaluators=[trajectory_evaluator],
)
```

```typescript TypeScript
  runMultiturnSimulation,
  createLLMAsJudge,
  type ChatCompletionMessage,
} from "openevals";

const lsClient = new Client();
const inputs = {
  messages: [
    {
      role: "user",
      content: "I want a refund for my car!",
    },
  ],
```

## 시뮬레이션된 사용자 페르소나 수정

위의 예시들은 `create_llm_simulated_user`에 전달된 `system` 파라미터로 정의된 동일한 시뮬레이션된 사용자 페르소나를 모든 입력 예시에 사용하여 실행됩니다. 데이터셋의 특정 항목에 대해 다른 페르소나를 사용하려면, 데이터셋 예시를 업데이트하여 원하는 `system` 프롬프트가 있는 추가 필드를 포함하고, 다음과 같이 시뮬레이션된 사용자를 생성할 때 해당 필드를 전달할 수 있습니다:

<CodeGroup>

```python Python
from openevals.simulators import run_multiturn_simulation, create_llm_simulated_user
from openevals.llm import create_llm_as_judge
from openevals.types import ChatCompletionMessage
from langsmith.wrappers import wrap_openai
from langsmith import Client
from openai import OpenAI

ls_client = Client()
examples = [
    {
        "inputs": {
            "messages": [{ "role": "user", "content": "I want a refund for my car!" }],
            "simulated_user_prompt": "You are an angry and belligerent customer who wants a refund for their car."
        },
    },
    {
        "inputs": {
            "messages": [{ "role": "user", "content": "Please give me a refund for my car." }],
            "simulated_user_prompt": "You are a nice customer who wants a refund for their car.",
        },
    }
]
dataset = ls_client.create_dataset(dataset_name="multiturn-with-personas")
ls_client.create_examples(
    dataset_id=dataset.id,
    examples=examples,
)
trajectory_evaluator = create_llm_as_judge(
    model="openai:o3-mini",
    prompt="Based on the below conversation, was the user satisfied?\n{outputs}",
    feedback_key="satisfaction",
)

def target(inputs: dict):
    # 추적을 위한 OpenAI 클라이언트 래핑
    client = wrap_openai(OpenAI())
    history = {}

    def app(next_message: ChatCompletionMessage, *, thread_id: str):
        if thread_id not in history:
            history[thread_id] = []
        history[thread_id] = history[thread_id] + [next_message]
        res = client.chat.completions.create(
            model="gpt-4.1-nano",
            messages=[
                {
                    "role": "system",
                    "content": "You are a patient and understanding customer service agent.",
                }
            ]
            + history[thread_id],
        )
        response = res.choices[0].message
        history[thread_id].append(response)
        return response

    user = create_llm_simulated_user(
        system=inputs["simulated_user_prompt"],
        model="openai:gpt-4.1-nano",
        fixed_responses=inputs["messages"],
    )
    res = run_multiturn_simulation(
        app=app,
        user=user,
        max_turns=5,
    )
    return res["trajectory"]

results = ls_client.evaluate(
    target,
    data=dataset.name,
    evaluators=[trajectory_evaluator],
)
```
