[Claude Code](https://docs.claude.com/en/docs/claude-code/overview)는 현재까지 가장 인상적이고 유용한 AI 코딩 도구 중 하나입니다. Claude Code는 모니터링과 관찰 가능성을 위한 이벤트를 발생시킵니다. LangSmith는 이러한 이벤트를 수집하고 표시하여 Claude Code가 내부적으로 수행하는 작업에 대한 상세한 로그를 제공합니다.

## 빠른 시작

Claude Code를 실행하는 환경에서 다음 환경 변수를 설정하여 LangSmith 추적을 Claude Code와 통합할 수 있습니다.

```bash
# Claude Code가 OTEL 이벤트를 발생시키도록 활성화
export CLAUDE_CODE_ENABLE_TELEMETRY=1

# 출력 형식을 Open Telemetry Protocol로 설정
export OTEL_LOGS_EXPORTER=otlp

# LangSmith는 JSON 형식 이벤트를 수집
export OTEL_EXPORTER_OTLP_LOGS_PROTOCOL=http/json

# Claude Code 로그는 LangSmith에 의해 Span으로 변환됨
export OTEL_EXPORTER_OTLP_LOGS_ENDPOINT=https://api.smith.langchain.com/otel/v1/claude_code

# API 키와 원하는 추적 프로젝트를 헤더를 통해 전달
export OTEL_EXPORTER_OTLP_HEADERS="x-api-key=<api-key>,Langsmith-Project=<project-name>"

# 사용자 입력 프롬프트를 로깅하려면 이 값을 true로 설정
export OTEL_LOG_USER_PROMPTS=1

# 이 값들을 설정한 후 Claude Code를 시작하면 이벤트가 LangSmith로 추적됨
claude
```

<Note>
Claude Code는 사용량 모니터링을 위해 [open telemetry 표준 이벤트](https://docs.claude.com/en/docs/claude-code/monitoring-usage#events)를 발생시키지만, 여기에는 LLM에 전달되는 실제 프롬프트와 메시지가 포함되지 않습니다.
</Note>

<Note>
자체 호스팅 LangSmith를 사용하는 경우, 기본 엔드포인트를 LangSmith API 엔드포인트로 변경하고 `/api/v1`을 추가하세요. 예: `OTEL_EXPORTER_OTLP_LOGS_ENDPOINT=https://ai-company.com/api/v1/otel/v1/claude_code`
</Note>
