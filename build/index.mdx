        <h1 class="flex whitespace-pre-wrap group font-semibold text-2xl sm:text-3xl mt-8">문서</h1>

        LangChain은 agent 엔지니어링을 위한 플랫폼입니다. Replit, Clay, Rippling, Cloudflare, Workday 등의 AI 팀들이 신뢰할 수 있는 agent를 개발하기 위해 LangChain 제품을 사용하고 있습니다.

        저희의 **오픈 소스 프레임워크**는 agent 구축을 돕습니다:

        - [**LangChain**](/oss/python/langchain/overview)은 원하는 모델 제공자를 사용하여 agent를 빠르게 구축할 수 있도록 도와줍니다.
        - [**LangGraph**](/oss/python/langgraph/overview)는 저수준 orchestration, 메모리, human-in-the-loop 지원을 통해 커스텀 agent의 모든 단계를 제어할 수 있게 합니다. 또한 durable execution으로 장기 실행 작업을 관리할 수 있습니다.

        [**LangSmith**](/langsmith/home)는 AI 팀이 실시간 프로덕션 데이터를 사용하여 지속적으로 테스트하고 개선할 수 있도록 돕는 플랫폼입니다. LangSmith는 다음을 제공합니다:

        - **Observability**: 상세한 tracing과 집계된 추세 메트릭을 통해 agent가 어떻게 생각하고 행동하는지 정확히 확인할 수 있습니다.
        - **Evaluation**: 프로덕션 데이터와 오프라인 데이터셋에서 agent 동작을 테스트하고 평가하여 지속적으로 개선할 수 있습니다.
        - **Deployment**: 장기 실행 작업을 위해 구축된 확장 가능한 인프라를 사용하여 원클릭으로 agent를 배포할 수 있습니다.
