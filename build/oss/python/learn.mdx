### LangGraph

LangChain의 [에이전트](/oss/python/langchain/agents) 구현은 [LangGraph](/oss/python/langgraph/overview) 프리미티브를 사용합니다.
더 깊은 커스터마이징이 필요한 경우, 에이전트를 LangGraph에서 직접 구현할 수 있습니다.

<Card title="커스텀 RAG 에이전트" icon="user-magnifying-glass" href="/oss/python/langgraph/agentic-rag" horizontal>
  세밀한 제어를 위해 LangGraph 프리미티브를 사용하여 RAG 에이전트를 구축합니다.
</Card>

<Card title="커스텀 SQL 에이전트" icon="database" href="/oss/python/langgraph/sql-agent" horizontal>
  최대한의 유연성을 위해 LangGraph에서 직접 SQL 에이전트를 구현합니다.
</Card>
