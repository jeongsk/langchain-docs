title: Dell PowerScale Document Loader

[Dell PowerScale](https://www.dell.com/en-us/shop/powerscale-family/sf/powerscale)은 온프레미스 또는 클라우드에 배포할 수 있는 업계 최고의 OneFS 파일시스템을 호스팅하는 엔터프라이즈 스케일 아웃 스토리지 시스템입니다.

이 문서 로더는 애플리케이션의 마지막 실행 이후 수정된 파일을 판별하고 수정된 파일만 처리를 위해 반환하는 PowerScale의 고유한 기능을 활용합니다. 이를 통해 변경되지 않은 파일을 다시 처리(청크 및 임베딩)할 필요가 없어져 전체 데이터 수집 워크플로우가 개선됩니다.

이 로더는 PowerScale의 MetadataIQ 기능이 활성화되어 있어야 합니다. 추가 정보는 GitHub 저장소에서 확인할 수 있습니다: [https://github.com/dell/powerscale-rag-connector](https://github.com/dell/powerscale-rag-connector)

## 초기화

이제 문서 로더를 인스턴스화할 수 있습니다:

### 일반 문서 로더

일반 문서 로더는 다음과 같은 방식으로 PowerScale에서 모든 파일을 점진적으로 로드하는 데 사용할 수 있습니다:

```python
from powerscale_rag_connector import PowerScaleDocumentLoader

loader = PowerScaleDocumentLoader(
    es_host_url="http://elasticsearch:9200",
    es_index_name="metadataiq",
    es_api_key="your-api-key",
    folder_path="/ifs/data",
)
```

### UnstructuredLoader 로더

선택적으로 `PowerScaleUnstructuredLoader`를 사용하여 변경된 파일을 찾고 _자동으로_ 파일을 처리하여 소스 파일의 요소를 생성할 수 있습니다. 이는 LangChain의 `UnstructuredLoader` 클래스를 사용하여 수행됩니다.

```python
from powerscale_rag_connector import PowerScaleUnstructuredLoader

# Or load files with the Unstructured Loader
loader = PowerScaleUnstructuredLoader(
    es_host_url="http://elasticsearch:9200",
    es_index_name="metadataiq",
    es_api_key="your-api-key",
    folder_path="/ifs/data",
    # 'elements' mode splits the document into more granular chunks
    # Use 'single' mode if you want the entire document as a single chunk
    mode="elements",
)
```

필드:

- `es_host_url`은 MetadataIQ Elasticsearch 데이터베이스의 엔드포인트입니다
- `es_index_index`는 PowerScale이 파일 시스템 메타데이터를 작성하는 인덱스의 이름입니다
- `es_api_key`는 elasticsearch API 키의 **인코딩된** 버전입니다
- `folder_path`는 변경 사항을 쿼리할 PowerScale의 경로입니다

## 로드

내부적으로 모든 코드는 PowerScale 및 MetadataIQ와 비동기식이며 load 및 lazy load 메서드는 python 생성기를 반환합니다. lazy load 함수를 사용하는 것이 좋습니다.

```python
for doc in loader.load():
    print(doc)
```


### 반환된 객체

두 문서 로더 모두 이전에 애플리케이션에 반환된 파일을 추적합니다. 다시 호출되면 문서 로더는 이전 실행 이후의 새 파일 또는 수정된 파일만 반환합니다.

- 반환된 [`Document`](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document)의 `metadata` 필드는 수정된 파일이 포함된 PowerScale의 경로를 반환합니다. 이 경로를 사용하여 NFS(또는 S3)를 통해 데이터를 읽고 애플리케이션에서 데이터를 처리합니다(예: 청크 및 임베딩 생성).
- `source` 필드는 PowerScale의 경로이며 로컬 시스템의 경로가 아닐 수 있습니다(마운트 전략에 따라 다름). OneFS는 전체 스토리지 시스템을 `/ifs`에 루트가 있는 단일 트리로 표현합니다.
- `change_types` 속성은 마지막 이후 발생한 변경 사항(예: 신규, 수정 또는 삭제)을 알려줍니다.

RAG 애플리케이션은 `change_types`의 정보를 사용하여 청크 및 벡터 저장소의 항목을 추가, 업데이트 또는 삭제할 수 있습니다.

`PowerScaleUnstructuredLoader`를 사용하면 `page_content` 필드가 Unstructured Loader의 데이터로 채워집니다

## 지연 로드

내부적으로 모든 코드는 PowerScale 및 MetadataIQ와 비동기식이며 load 및 lazy load 메서드는 python 생성기를 반환합니다. lazy load 함수를 사용하는 것이 좋습니다.

```python
for doc in loader.lazy_load():
    print(doc)  # do something specific with the document
```

load 함수와 동일한 [`Document`](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document)가 위에서 언급한 모든 속성과 함께 반환됩니다.
