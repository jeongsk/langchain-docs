title: Recursive URL
---

`RecursiveUrlLoader`를 사용하면 루트 URL에서 모든 하위 링크를 재귀적으로 스크래핑하고 Documents로 파싱할 수 있습니다.

| Source | Document Lazy Loading | Native Async Support

## 설정

### 자격 증명

`RecursiveUrlLoader`를 사용하는 데 자격 증명은 필요하지 않습니다.

### 설치

`RecursiveUrlLoader`는 `langchain-community` 패키지에 포함되어 있습니다. 다른 필수 패키지는 없지만, `beautifulsoup4`를 설치하면 더 풍부한 기본 Document 메타데이터를 얻을 수 있습니다.

```python
%pip install -qU langchain-community beautifulsoup4 lxml
```

## 인스턴스화

이제 문서 로더 객체를 인스턴스화하고 Documents를 로드할 수 있습니다:

```python
from langchain_community.document_loaders import RecursiveUrlLoader

loader = RecursiveUrlLoader(
    "https://docs.python.org/3.9/",
    # max_depth=2,
    # use_async=False,
    # extractor=None,
    # metadata_extractor=None,
    # exclude_dirs=(),
    # timeout=10,
    # check_response_status=True,
    # continue_on_failure=True,
    # prevent_outside=True,
    # base_url=None,
    # ...
)
```

## 로드

`.load()`를 사용하여 모든 Documents를 동기적으로 메모리에 로드하며, 방문한 URL당 하나의 Document가 생성됩니다. 초기 URL에서 시작하여 지정된 max_depth까지 모든 링크된 URL을 재귀적으로 탐색합니다.

docs = loader.load()

## 지연 로딩

많은 수의 Documents를 로딩하고 다운스트림 작업이 로드된 모든 Documents의 하위 집합에 대해 수행될 수 있는 경우, Documents를 한 번에 하나씩 지연 로드하여 메모리 사용량을 최소화할 수 있습니다:

```python
pages = []
for doc in loader.lazy_load():
    pages.append(doc)
    if len(pages) >= 10:
        # 페이지 단위 작업을 수행합니다. 예:
        # index.upsert(page)

        pages = []
```

## Extractor 추가

기본적으로 로더는 각 링크의 원시 HTML을 Document 페이지 콘텐츠로 설정합니다. 이 HTML을 사람/LLM 친화적인 형식으로 파싱하려면 사용자 정의 `extractor` 메서드를 전달할 수 있습니다:

```python
import re

from bs4 import BeautifulSoup


def bs4_extractor(html: str) -> str:
    soup = BeautifulSoup(html, "lxml")
    return re.sub(r"\n\n+", "\n\n", soup.text).strip()


loader = RecursiveUrlLoader("https://docs.python.org/3.9/", extractor=bs4_extractor)
docs = loader.load()
print(docs[0].page_content[:200])
```

## API 레퍼런스

이 예제들은 기본 `RecursiveUrlLoader`를 수정할 수 있는 몇 가지 방법을 보여주지만, 사용 사례에 가장 적합하도록 만들 수 있는 수정 사항이 더 많이 있습니다. `link_regex` 및 `exclude_dirs` 매개변수를 사용하면 원하지 않는 URL을 필터링할 수 있고, `aload()` 및 `alazy_load()`는 비동기 로딩에 사용할 수 있습니다.

`RecursiveUrlLoader`를 구성하고 호출하는 방법에 대한 자세한 정보는 API 레퍼런스를 참조하세요: [python.langchain.com/api_reference/community/document_loaders/langchain_community.document_loaders.recursive_url_loader.RecursiveUrlLoader.html](https://python.langchain.com/api_reference/community/document_loaders/langchain_community.document_loaders.recursive_url_loader.RecursiveUrlLoader.html).
