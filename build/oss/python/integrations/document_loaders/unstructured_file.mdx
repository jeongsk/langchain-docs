이 노트북은 `Unstructured` [문서 로더](https://python.langchain.com/docs/concepts/document_loaders)를 사용하여 다양한 유형의 파일을 로드하는 방법을 다룹니다. `Unstructured`는 현재 텍스트 파일, PowerPoint, HTML, PDF, 이미지 등의 로딩을 지원합니다.

필수 시스템 종속성 설정을 포함한 Unstructured를 로컬로 설정하는 방법에 대한 자세한 지침은 [이 가이드](/oss/python/integrations/providers/unstructured)를 참조하세요.

## 설정

### 자격 증명

기본적으로 `langchain-unstructured`는 파티셔닝 로직을 Unstructured API로 오프로딩해야 하는 더 작은 설치 공간을 설치하며, 이를 위해서는 API 키가 필요합니다. 로컬 설치를 사용하는 경우 API 키가 필요하지 않습니다. API 키를 얻으려면 [이 사이트](https://unstructured.io)로 이동하여 API 키를 받은 다음 아래 셀에 설정하세요:

```python
import getpass
import os

if "UNSTRUCTURED_API_KEY" not in os.environ:
    os.environ["UNSTRUCTURED_API_KEY"] = getpass.getpass(
        "Enter your Unstructured API key: "
    )
```

### 설치

#### 일반 설치

나머지 노트북을 실행하려면 다음 패키지가 필요합니다.

```python
# API 파티셔닝과 호환되는 패키지 설치
%pip install -qU langchain-unstructured unstructured-client unstructured "unstructured[pdf]" python-magic
```

#### 로컬 설치

파티셔닝 로직을 로컬로 실행하려면 [여기 Unstructured 문서](https://docs.unstructured.io/open-source/installation/full-installation)에 설명된 대로 시스템 종속성 조합을 설치해야 합니다.

예를 들어 Mac에서는 다음을 사용하여 필요한 종속성을 설치할 수 있습니다:

```bash
# 기본 종속성
brew install libmagic poppler tesseract

# XML / HTML 문서 파싱하는 경우:
brew install libxml2 libxslt
```

로컬에 필요한 `pip` 종속성을 설치할 수 있습니다:

```bash
pip install "langchain-unstructured[local]"
```

## 초기화

`UnstructuredLoader`는 다양한 파일 유형에서 로딩할 수 있습니다. `unstructured` 패키지에 대한 모든 내용을 읽으려면 해당 [문서](https://docs.unstructured.io/open-source/introduction/overview/)를 참조하세요. 이 예제에서는 텍스트 파일과 PDF 파일에서 로딩하는 방법을 보여줍니다.

```python
from langchain_unstructured import UnstructuredLoader

file_paths = [
    "./example_data/layout-parser-paper.pdf",
    "./example_data/state_of_the_union.txt",
]


loader = UnstructuredLoader(file_paths)
```

## 후처리

추출 후 `unstructured` 요소를 후처리해야 하는 경우 `UnstructuredLoader`를 인스턴스화할 때 `post_processors` kwarg에 `str` -> `str` 함수 목록을 전달할 수 있습니다. 이는 다른 Unstructured 로더에도 적용됩니다. 아래는 예제입니다.

```python
from langchain_unstructured import UnstructuredLoader
from unstructured.cleaners.core import clean_extra_whitespace

loader = UnstructuredLoader(
    "./example_data/layout-parser-paper.pdf",
    post_processors=[clean_extra_whitespace],
)

docs = loader.load()

docs[5:10]
```

## Unstructured API

더 작은 패키지로 시작하고 최신 파티셔닝을 받으려면 `unstructured-client`와 `langchain-unstructured`를 설치할 수 있습니다. `UnstructuredLoader`에 대한 자세한 내용은 [Unstructured 공급자 페이지](https://python.langchain.com/v0.1/docs/integrations/document_loaders/unstructured_file/)를 참조하세요.

`api_key`를 전달하고 `partition_via_api=True`를 설정하면 로더는 호스팅된 Unstructured 서버리스 API를 사용하여 문서를 처리합니다. [여기](https://unstructured.io/api-key/)에서 무료 Unstructured API 키를 생성할 수 있습니다.

Unstructured API를 자체 호스팅하거나 로컬로 실행하려면 [여기](https://github.com/Unstructured-IO/unstructured-api#dizzy-instructions-for-using-the-docker-image)의 지침을 확인하세요.

```python
from langchain_unstructured import UnstructuredLoader

loader = UnstructuredLoader(
    file_path="example_data/fake.docx",
    api_key=os.getenv("UNSTRUCTURED_API_KEY"),
    partition_via_api=True,
)

docs = loader.load()
docs[0]
```

## 청킹

`UnstructuredLoader`는 `UnstructuredFileLoader` 및 기타 이전 로더와 같이 텍스트 그룹화를 위한 `mode` 매개변수를 지원하지 않습니다. 대신 "청킹"을 지원합니다. unstructured의 청킹은 일반 텍스트 기능(예: "\n\n" 또는 "\n"과 같은 문자 시퀀스)을 기반으로 청크를 형성하는 친숙한 다른 청킹 메커니즘과 다릅니다. 대신 모든 문서는 각 문서 형식에 대한 특정 지식을 사용하여 문서를 의미 단위(문서 요소)로 분할하며 단일 요소가 원하는 최대 청크 크기를 초과하는 경우에만 텍스트 분할에 의존합니다. 일반적으로 청킹은 최대 청크 크기를 초과하지 않고 가능한 한 큰 청크를 형성하기 위해 연속 요소를 결합합니다. 청킹은 CompositeElement, Table 또는 TableChunk 요소의 시퀀스를 생성합니다. 각 "청크"는 이 세 가지 유형 중 하나의 인스턴스입니다.

청킹 옵션에 대한 자세한 내용은 [이 페이지](https://docs.unstructured.io/open-source/core-functionality/chunking)를 참조하세요. 하지만 `mode="single"`과 동일한 동작을 재현하려면 `chunking_strategy="basic"`, `max_characters=<some-really-big-number>`, `include_orig_elements=False`를 설정할 수 있습니다.

## 웹 페이지 로딩

`UnstructuredLoader`는 로컬로 실행할 때 기본 Unstructured [partition](https://docs.unstructured.io/open-source/core-functionality/partitioning)의 `url` 매개변수를 채우는 `web_url` kwarg를 허용합니다. 이를 통해 HTML 웹 페이지와 같은 원격으로 호스팅되는 문서를 파싱할 수 있습니다.

예제 사용법:

```python
from langchain_unstructured import UnstructuredLoader

loader = UnstructuredLoader(web_url="https://www.example.com")
docs = loader.load()

for doc in docs:
    print(f"{doc}\n")
```
