## 초기화

이제 모델 객체를 인스턴스화하고 문서를 로드할 수 있습니다.

"single"과 "elements"의 두 가지 모드 중 하나로 로더를 실행할 수 있습니다. "single" 모드를 사용하면 문서가 하나의 [`Document`](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document) 객체로 반환됩니다. "elements" 모드를 사용하면 unstructured 라이브러리가 문서를 `Title` 및 `NarrativeText`와 같은 요소로 분할합니다. 모드 다음에 추가적인 `unstructured` kwargs를 전달하여 다른 `unstructured` 설정을 적용할 수 있습니다.

```python
from langchain_community.document_loaders import UnstructuredMarkdownLoader

loader = UnstructuredMarkdownLoader(
    "./example_data/example.md",
    mode="single",
    strategy="fast",
)
```

docs = loader.load()

## 요소 로드

이 예제에서는 `elements` 모드로 로드하여 마크다운 문서의 다양한 요소 목록을 반환합니다:

```python
from langchain_community.document_loaders import UnstructuredMarkdownLoader

loader = UnstructuredMarkdownLoader(
    "./example_data/example.md",
    mode="elements",
    strategy="fast",
)

docs = loader.load()
len(docs)
```

```output
29
```

`example.md` 파일에서 29개의 요소가 추출된 것을 볼 수 있습니다. 예상대로 첫 번째 요소는 문서의 제목입니다:

```python
docs[0].page_content
```

```output
'Sample Markdown Document'
```
