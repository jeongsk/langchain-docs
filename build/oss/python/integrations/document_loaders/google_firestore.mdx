## 기본 사용법

### 문서 저장

`FirestoreLoader.add_documents(<documents>)`로 langchain 문서를 저장합니다. 기본적으로 컬렉션은 `page_content` 및 `metadata` 유형의 `map`이라는 두 개의 필드를 가진 문서로 채워집니다.

```python
from langchain_core.documents import Document
from langchain_google_firestore import FirestoreSaver

saver = FirestoreSaver()

data = [Document(page_content="Hello, World!")]

saver.upsert_documents(data)
```

#### 새 컬렉션에 저장

컬렉션은 존재하지 않는 경우 자동으로 생성됩니다.

```python
saver = FirestoreSaver("Collection")

saver.upsert_documents(data)
```

### 문서 로드

`FirestoreLoader.load()` 또는 `Firestore.lazy_load()`로 langchain 문서를 로드합니다. `lazy_load`는 반복 중에만 쿼리를 평가하는 제너레이터를 반환합니다. `FirestoreLoader` 클래스를 초기화하려면 다음이 필요합니다:

1. `source` - Firestore 컬렉션 또는 쿼리에 대한 참조.

```python
from langchain_google_firestore import FirestoreLoader

loader_collection = FirestoreLoader("Collection")

data_collection = loader_collection.load()
```

### 문서 삭제

`FirestoreSaver.delete_documents(<documents>)`로 Firestore 컬렉션에서 langchain 문서 목록을 삭제합니다.

```python
saver = FirestoreSaver()

saver.delete_documents(data)

# 컬렉션은 비어 있거나 존재하지 않음
data_collection = loader_collection.load()
print(f"Documents left: {len(data_collection)}")
```

## 고급 사용법

### 자체 문서 참조 로드

사용자는 Firestore 컬렉션 대신 DocumentReference를 제공할 수 있습니다.

```python
from google.cloud import firestore

client = firestore.Client()
doc_ref = client.collection("foo").document("bar")

loader_doc_ref = FirestoreLoader(doc_ref)
```

### 쿼리에서 로드

사용자는 컬렉션 또는 CollectionGroup 쿼리에서 로드할 수 있습니다.

```python
from google.cloud.firestore import CollectionGroup, FieldFilter

col_ref = client.collection("col_group")
collection_group = CollectionGroup(col_ref)

loader_group = FirestoreLoader(collection_group.where(filter=FieldFilter("region", "==", "west_coast")))
```

### 사용자 정의 클라이언트

사용자는 사용자 정의 클라이언트를 전달할 수 있습니다.

```python
from google.auth import compute_engine
from google.cloud.firestore import Client

client = Client(database="non-default-db", creds=compute_engine.Credentials())
loader = FirestoreLoader(
    source="foo/bar/subcol",
    client=client,
)
```

### 사용자 정의 문서 페이지 콘텐츠 및 메타데이터 필드 설정

`page_content_fields` 및 `metadata_fields`를 통해 페이지 콘텐츠 및 메타데이터가 Document로 로드되는 방식을 사용자 정의할 수 있습니다.

```python
loader = FirestoreLoader(
    source="foo/bar/subcol",
    page_content_fields=["data_field"],
    metadata_fields=["metadata_field"],
)
```

#### 메타데이터와 유사하게 페이지 콘텐츠 필드 사용자 정의

`page_content_fields` 및 `metadata_fields`를 모두 지정하면 두 목록에 모두 나타나는 필드는 무시됩니다.

```python
loader = FirestoreLoader(
    source="foo/bar/subcol",
    page_content_fields=["data_field"],
    metadata_fields=["data_field"],
)
```
