이 노트북은 __UnDatasIO document loader__를 시작하기 위한 빠른 개요를 제공합니다. UnDatasIO는 PDF, PNG, JPG, JPEG, JFIF를 포함한 다양한 문서 형식의 효율적인 로드 및 파싱을 가능하게 하며, 문서 지연 로딩 및 네이티브 비동기 지원과 같은 기능을 UnDatasIO의 안전한 클라우드 API를 통해 제공합니다. 이러한 기능들은 처리된 데이터를 RAG와 같은 생성형 AI 워크플로우에 즉시 사용할 수 있도록 합니다.

자세한 문서는 공식 API 레퍼런스를 참조하세요.

## 개요

### 로더 기능

| Source | Document Lazy Loading | Native Async Support |
| :---: | :---: | :---: |

## 설정

### 자격 증명

UnDatasIO는 API 토큰이 필요합니다.  
[undatas.io](https://undatas.io)에서 무료 토큰을 생성하고 아래 셀에 설정하세요:

```python
import getpass
import os

if "UNDATASIO_TOKEN" not in os.environ:
    os.environ["UNDATASIO_TOKEN"] = getpass.getpass(
        "Enter your UnDatasIO API token: "
    )
```

### 초기화

__UnDatasIOLoader__는 UnDatasIO 클라우드 API를 통한 단일 파일 업로드 및 파싱을 지원합니다.

```python
from langchain_undatasio import UnDatasIOLoader

loader = UnDatasIOLoader(
    token=os.environ["UNDATASIO_TOKEN"],
    file_path="demo.pdf"
)
```

### 로드

```python
docs = loader.load()
docs[0]
```

### 지연 로드

__UnDatasIOLoader__는 메모리 효율적인 반복을 위한 지연 로딩을 지원합니다.

```python
pages = []
for doc in loader.lazy_load():
    pages.append(doc)

pages[0]
```
