>[Project Gutenberg](https://www.gutenberg.org/about/)는 60,000권 이상의 무료 전자책을 제공하는 온라인 도서관입니다.

이 가이드는 [Gutenberg](https://www.gutenberg.org/about/)에서 데이터를 로드하는 방법을 보여줍니다.

```python
from langchain_community.document_loaders import GutenbergLoader
```

```python
loader = GutenbergLoader("https://www.gutenberg.org/cache/epub/69972/pg69972.txt")
```

```python
data = loader.load()
```

```python
data[0].page_content[:300]
```

```output
'The Project Gutenberg eBook of The changed brides, by Emma Dorothy\r\nEliza Nevitte Southworth\r\n\r\nThis eBook is for the use of anyone anywhere in the United States and\r\nmost other parts of the world at no cost and with almost no restrictions\r\nwhatsoever. You may copy it, give it away or re-use'
```

```python
data[0].metadata
```

```output
{'source': 'https://www.gutenberg.org/cache/epub/69972/pg69972.txt'}
```
