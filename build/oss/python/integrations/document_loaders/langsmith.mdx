## 설정

LangSmith 문서 로더에 액세스하려면 `langchain-core`를 설치하고, [LangSmith](https://langsmith.com) 계정을 생성하고 API 키를 발급받아야 합니다.

### 인증 정보

[langsmith.com](https://langsmith.com)에서 가입하고 API 키를 생성하세요. 이 작업을 완료한 후 LANGSMITH_API_KEY 환경 변수를 설정하세요:

```python
import getpass
import os

if not os.environ.get("LANGSMITH_API_KEY"):
    os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

자동화된 최고 수준의 추적을 원하는 경우 LangSmith 추적도 활성화할 수 있습니다:

```python
# os.environ["LANGSMITH_TRACING"] = "true"
```

### 예제 데이터셋 복제

이 예제에서는 공개 LangSmith 데이터셋을 복제하고 로드합니다. 복제하면 개인 LangSmith 계정에 이 데이터셋의 사본이 생성됩니다. 개인 사본이 있는 데이터셋만 로드할 수 있습니다.

```python
from langsmith import Client as LangSmithClient

ls_client = LangSmithClient()

dataset_name = "LangSmith Few Shot Datasets Notebook"
dataset_public_url = (
    "https://smith.langchain.com/public/55658626-124a-4223-af45-07fb774a6212/d"
)

ls_client.clone_public_dataset(dataset_public_url)
```

## 초기화

이제 문서 로더를 인스턴스화하고 문서를 로드할 수 있습니다:

```python
from langchain_core.document_loaders import LangSmithLoader

loader = LangSmithLoader(
    dataset_name=dataset_name,
    content_key="question",
    limit=50,
    # format_content=...,
    # ...
)
```

docs = loader.load()
print(docs[0].page_content)
