## 데이터 쿼리 예시

```python
from langchain_community.document_loaders.fauna import FaunaLoader

secret = "<enter-valid-fauna-secret>"
query = "Item.all()"  # Fauna 쿼리. 컬렉션 이름이 "Item"이라고 가정합니다
field = "text"  # 페이지 콘텐츠가 포함된 필드. 필드 이름이 "text"라고 가정합니다

loader = FaunaLoader(query, field, secret)
docs = loader.lazy_load()

for value in docs:
    print(value)
```

### 페이지네이션을 사용한 쿼리

더 많은 데이터가 있는 경우 `after` 값을 받습니다. 쿼리에 `after` 문자열을 전달하여 커서 이후의 값을 가져올 수 있습니다.

자세한 내용은 [이 링크](https://fqlx-beta--fauna-docs.netlify.app/fqlx/beta/reference/schema_entities/set/static-paginate)를 참조하세요

```python
query = """
Item.paginate("hs+DzoPOg ... aY1hOohozrV7A")
Item.all()
"""
loader = FaunaLoader(query, field, secret)
```
