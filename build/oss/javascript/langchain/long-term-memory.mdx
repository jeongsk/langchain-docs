## 개요

LangChain 에이전트는 장기 메모리를 활성화하기 위해 [LangGraph 영속성](/oss/javascript/langgraph/persistence#memory-store)을 사용합니다. 이는 고급 주제이며 사용하려면 LangGraph에 대한 지식이 필요합니다.


## 메모리 저장

LangGraph는 장기 메모리를 [스토어](/oss/javascript/langgraph/persistence#memory-store)에 JSON 문서로 저장합니다.

각 메모리는 커스텀 `namespace`(폴더와 유사) 및 고유한 `key`(파일 이름과 유사) 아래에 구성됩니다. 네임스페이스는 종종 사용자 또는 조직 ID 또는 정보를 쉽게 구성할 수 있게 하는 다른 레이블을 포함합니다.

이 구조는 메모리의 계층적 구성을 가능하게 합니다. 그런 다음 콘텐츠 필터를 통해 네임스페이스 간 검색이 지원됩니다.



```typescript
import { InMemoryStore } from "@langchain/langgraph";

const embed = (texts: string[]): number[][] => {
    // 실제 임베딩 함수 또는 LangChain 임베딩 객체로 교체하세요
    return texts.map(() => [1.0, 2.0]);
};

// InMemoryStore는 데이터를 인메모리 딕셔너리에 저장합니다. 프로덕션에서는 DB 기반 스토어를 사용하세요.
const store = new InMemoryStore({ index: { embed, dims: 2 } }); // [!code highlight]
const userId = "my-user";
const applicationContext = "chitchat";
const namespace = [userId, applicationContext]; // [!code highlight]

await store.put( // [!code highlight]
    namespace,
    "a-memory",
    {
        rules: [
            "User likes short, direct language",
            "User only speaks English & TypeScript",
        ],
        "my-key": "my-value",
    }
);

// ID로 "메모리" 가져오기
const item = await store.get(namespace, "a-memory"); // [!code highlight]

// 이 네임스페이스 내에서 "메모리" 검색, 콘텐츠 동등성으로 필터링, 벡터 유사도로 정렬
const items = await store.search( // [!code highlight]
    namespace,
    {
        filter: { "my-key": "my-value" },
        query: "language preferences"
    }
);
```


메모리 스토어에 대한 자세한 내용은 [영속성](/oss/javascript/langgraph/persistence#memory-store) 가이드를 참조하세요.

## 도구에서 장기 메모리 읽기



```typescript 에이전트가 사용자 정보를 조회하는 데 사용할 수 있는 도구
import * as z from "zod";
import { createAgent, tool } from "langchain";
import { InMemoryStore, type Runtime } from "@langchain/langgraph";

// InMemoryStore는 데이터를 인메모리 딕셔너리에 저장합니다. 프로덕션에서는 DB 기반 스토어를 사용하세요.
const store = new InMemoryStore(); // [!code highlight]
const contextSchema = z.object({
    userId: z.string(),
});

// put 메서드를 사용하여 스토어에 샘플 데이터 쓰기
await store.put( // [!code highlight]
    ["users"], // 관련 데이터를 그룹화하는 네임스페이스(사용자 데이터를 위한 users 네임스페이스)
    "user_123", // 네임스페이스 내의 키(사용자 ID를 키로 사용)
    {
        name: "John Smith",
        language: "English",
    } // 주어진 사용자에 대해 저장할 데이터
);

const getUserInfo = tool(
  // 사용자 정보를 조회합니다.
  async (_, runtime: Runtime<z.infer<typeof contextSchema>>) => {
    // 스토어에 접근 - `createAgent`에 제공된 것과 동일
    const userId = runtime.context?.userId;
    if (!userId) {
      throw new Error("userId is required");
    }
    // 스토어에서 데이터 검색 - 값과 메타데이터가 있는 StoreValue 객체 반환
    const userInfo = await runtime.store.get(["users"], userId);
    return userInfo?.value ? JSON.stringify(userInfo.value) : "Unknown user";
  },
  {
    name: "getUserInfo",
    description: "Look up user info by userId from the store.",
    schema: z.object({}),
  }
);

const agent = createAgent({
    model: "openai:gpt-4o-mini",
    tools: [getUserInfo],
    contextSchema,
    // 에이전트에 스토어 전달 - 도구 실행 시 에이전트가 스토어에 접근할 수 있도록 함
    store, // [!code highlight]
});

// 에이전트 실행
const result = await agent.invoke(
    { messages: [{ role: "user", content: "look up user information" }] },
    { context: { userId: "user_123" } } // [!code highlight]
);

console.log(result.messages.at(-1)?.content);
/**
 * 출력:
 * User Information:
 * - Name: John Smith
 * - Language: English
 */
```

## 도구에서 장기 메모리 쓰기



```typescript 사용자 정보를 업데이트하는 도구의 예시
import * as z from "zod";
import { tool, createAgent, type AgentRuntime } from "langchain";
import { InMemoryStore, type Runtime } from "@langchain/langgraph";

// InMemoryStore는 데이터를 인메모리 딕셔너리에 저장합니다. 프로덕션에서는 DB 기반 스토어를 사용하세요.
const store = new InMemoryStore(); // [!code highlight]

const contextSchema = z.object({
    userId: z.string(),
});

// 스키마는 LLM을 위한 사용자 정보의 구조를 정의합니다
const UserInfo = z.object({
    name: z.string(),
});

// 에이전트가 사용자 정보를 업데이트할 수 있도록 하는 도구(채팅 애플리케이션에 유용)
const saveUserInfo = tool(
  async (userInfo: z.infer<typeof UserInfo>, runtime: Runtime<z.infer<typeof contextSchema>>) => {
    const userId = runtime.context?.userId;
    if (!userId) {
      throw new Error("userId is required");
    }
    // 스토어에 데이터 저장(네임스페이스, 키, 데이터)
    await runtime.store.put(["users"], userId, userInfo);
    return "Successfully saved user info.";
  },
  {
    name: "save_user_info",
    description: "Save user info",
    schema: UserInfo,
  }
);

const agent = createAgent({
    model: "openai:gpt-4o-mini",
    tools: [saveUserInfo],
    contextSchema,
    store, // [!code highlight]
});

// 에이전트 실행
await agent.invoke(
    { messages: [{ role: "user", content: "My name is John Smith" }] },
    // 어떤 사용자의 정보를 업데이트하는지 식별하기 위해 컨텍스트에 userId 전달
    { context: { userId: "user_123" } } // [!code highlight]
);

// 스토어에 직접 접근하여 값을 가져올 수 있습니다
const result = await store.get(["users"], "user_123");
console.log(result?.value); // Output: { name: "John Smith" }
```
