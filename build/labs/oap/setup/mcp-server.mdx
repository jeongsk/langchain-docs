title: MCP 서버
---
<Tip>
Open Agent Platform은 현재 스트리밍 가능한 HTTP 요청을 지원하는 MCP 서버에만 연결할 수 있습니다. **2025년 5월 10일** 기준으로 이를 지원하는 MCP 서버가 많지 않기 때문에, [Arcade](https://arcade-ai.com/)의 MCP 서버에 연결된 데모 애플리케이션을 제공하고 있습니다.
</Tip>

Open Agent Platform은 스트리밍 가능한 HTTP 요청을 지원하는 MCP 서버에 에이전트를 연결할 수 있도록 일급 지원을 제공합니다. MCP 서버는 두 가지 방법으로 설정할 수 있습니다.

먼저 `apps/web/` 디렉터리 내의 환경 변수 `NEXT_PUBLIC_MCP_SERVER_URL`에 MCP 서버 URL을 설정합니다. OAP 웹 앱이 MCP 서버로 요청을 보낼 때 URL 끝에 `/mcp`를 추가하므로, 이 URL은 `/mcp`로 끝나지 *않아야* 합니다.

예를 들어 MCP 서버 URL이 다음과 같다면:

```bash
https://api.arcade.dev/v1/mcps/arcade-anon/mcp
```

환경 변수는 다음과 같이 설정해야 합니다:

```bash
NEXT_PUBLIC_MCP_SERVER_URL="https://api.arcade.dev/v1/mcps/arcade-anon" # /mcp 제외
```

### 인증이 필요한 서버

인증이 필요한 MCP 서버에 연결하려면 `NEXT_PUBLIC_MCP_AUTH_REQUIRED=true`로 설정해야 합니다. MCP 인증은 다음과 같은 방식으로 작동합니다:

웹 클라이언트가 프록시 라우트(`/api/oap_mcp`)로 요청을 보냅니다. 이 API 라우트 내부에서는 Supabase의 JWT를 사용하여 MCP 서버와 인증합니다. 이는 MCP 서버에 Supabase JWT(또는 다른 인증 제공자를 사용하는 경우 다른 JWT)를 MCP 액세스 토큰으로 교환할 수 있는 엔드포인트를 구현해야 함을 의미합니다. 이 액세스 토큰은 이후 MCP 서버로의 요청을 인증하는 데 사용됩니다. 교환이 완료되면 MCP 액세스 토큰을 사용하여 사용자를 대신해 MCP 서버로 요청을 보내며, 요청의 `Authorization` 헤더를 통해 토큰을 전달합니다. 요청 응답을 클라이언트에게 다시 보낼 때는 응답의 `x-mcp-access-token` 헤더에 MCP 액세스 토큰을 포함합니다. 이를 통해 클라이언트는 매번 MCP 서버와 인증하지 않고도 향후 MCP 서버 요청에 MCP 액세스 토큰을 사용할 수 있습니다. 기본적으로 1시간 후에 만료되도록 설정됩니다.

`NEXT_PUBLIC_MCP_SERVER_URL`에 설정된 URL은 프록시 라우트가 MCP 서버로 요청을 보내기 위해 끝에 `/mcp`를 추가하고, MCP 서버의 OAuth 토큰 엔드포인트로 요청을 보내기 위해 `/oauth/token`을 추가할 수 있도록 형식화되어야 합니다.

선택적으로 `MCP_TOKENS` 환경 변수에 `access_token` 필드를 포함하는 객체를 설정할 수 있습니다. 이 환경 변수가 설정되면 해당 액세스 토큰을 사용하여 MCP 서버로의 요청을 인증하려고 시도합니다. 이는 테스트용으로 유용하거나 Supabase가 아닌 다른 인증 제공자를 사용하고자 할 때 유용합니다.

### 인증이 필요하지 않은 서버

인증이 필요하지 않은 MCP 서버에 연결하려면 `NEXT_PUBLIC_MCP_SERVER_URL` 환경 변수를 MCP 서버의 URL로 설정해야 합니다. 이 URL이 설정되어 있고 `NEXT_PUBLIC_MCP_AUTH_REQUIRED`가 설정되지 않았거나 `true`로 설정되지 않은 경우, 프록시 라우트에서 OAuth 요청을 실행하지 않고 MCP 서버를 직접 호출합니다.

### MCP 서버 URL 변경

MCP 서버 URL을 변경하는 경우, 모든 에이전트가 새 URL을 사용하도록 업데이트해야 합니다. 이를 위한 스크립트가 이 저장소에 포함되어 있습니다. 이 스크립트는 [`apps/web/scripts/update-agents-mcp-url.ts`](https://github.com/langchain-ai/open-agent-platform/blob/main/apps/web/scripts/update-agents-mcp-url.ts)에서 찾을 수 있습니다.

에이전트의 MCP 서버 URL을 업데이트하려면 최신 MCP 서버 URL을 환경 변수 `NEXT_PUBLIC_MCP_SERVER_URL`에 설정하고, `NEXT_PUBLIC_DEPLOYMENTS`에 배포 정보를, `LANGSMITH_API_KEY`에 LangSmith API 키를 설정해야 합니다(이는 스크립트가 LangSmith 인증을 사용하여 LangGraph 서버와 인증하고 사용자 인증을 우회하기 때문입니다). 그런 다음 스크립트를 실행합니다:

```bash
# apps/web 디렉터리 내에 있는지 확인
cd apps/web

# TSX를 통해 스크립트 실행
npx tsx scripts/update-agents-mcp-url.ts
```

이 스크립트는 나열된 모든 배포에서 모든 에이전트를 가져옵니다. 그런 다음 주어진 에이전트가 MCP 서버를 지원하는지 확인합니다. 지원하는 경우 MCP 서버 URL이 이미 새 URL로 설정되어 있지 않은지 확인합니다. 설정되어 있지 않으면 에이전트의 설정을 새 URL을 사용하도록 업데이트합니다.
