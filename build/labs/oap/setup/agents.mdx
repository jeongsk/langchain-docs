Open Agent Platform 설정의 첫 번째 단계는 에이전트를 배포하고 구성하는 것입니다. 이를 돕기 위해 Open Agent Platform에 특화되어 커스터마이징된 세 가지 사전 빌드 에이전트를 제공합니다:

- [Tools Agent](https://github.com/langchain-ai/oap-langgraph-tools-agent)
- [Supervisor Agent](https://github.com/langchain-ai/oap-agent-supervisor)
- [Deep Research Agent](https://github.com/langchain-ai/oap-deep-researcher)

## 에이전트 배포

인스턴스에서 이러한 에이전트를 사용하려면 다음 단계를 수행하세요:

1. 리포지토리를 클론합니다
2. README의 지침을 따릅니다
3. 에이전트를 LangSmith에 배포하거나, `langgraph dev`를 실행하여 로컬에서 에이전트를 실행합니다.

## API 키

이러한 에이전트는 모델용 API 키가 필요하며, 경우에 따라 다른 기능(예: 검색 도구)을 위한 API 키도 필요합니다.
개발자는 사용자가 Open Agent Platform의 설정 페이지에서 이러한 API 키를 구성할 수 있도록 허용할 수 있습니다.
데모 에이전트에서는 `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GOOGLE_API_KEY`, `TAVILY_API_KEY`를 노출했으며, 이는 커스텀 에이전트에 대해서도 쉽게 확장할 수 있습니다.


사용자가 이 페이지에서 설정한 키는 런타임 구성의 일부로 `apiKeys` 구성 가능 필드 아래에서 모든 에이전트에 전달됩니다.
개발자는 사용자가 자신의 API 키를 가져오도록 요구하거나, LangSmith 배포 자체에 설정된 환경 변수로 폴백하도록 선택할 수 있습니다.

    <Tip>
    OAP의 데모 인스턴스를 사용할 때 Tools Agent와 Supervisor는 먼저 사용자가 OAP에서 설정한 API 키를 사용하지만, 기본 배포에서 LangChain 팀이 설정한 API 키로 폴백합니다.
    데모 인스턴스에서 Deep Researcher는 사용자가 OAP에서 자신의 API 키를 설정해야 **합니다**.
    </Tip>

## 구성

배포 또는 로컬 실행 후, 구성 환경 변수를 설정하여 Open Agent Platform 인스턴스에 연결할 수 있습니다. 구성 객체는 다음과 같습니다:

```json
{
  "id": "배포의 프로젝트 ID입니다. 로컬에서 실행되는 LangGraph 서버의 경우 UUID 버전 4가 될 수 있습니다.",
  "tenantId": "LangSmith 계정의 테넌트 ID입니다. 로컬에서 실행되는 LangGraph 서버의 경우 UUID 버전 4가 될 수 있습니다.",
  "deploymentUrl": "배포에 대한 API URL입니다.",
  "name": "배포의 커스텀 이름입니다",
  "isDefault": "이 배포가 기본 배포인지 여부입니다. 하나의 배포에서만 true로 설정해야 합니다.",
  "defaultGraphId": "전체 OAP 인스턴스의 기본 그래프의 그래프 ID입니다. RAG 및 MCP 도구를 지원하는 그래프의 그래프 ID로 설정하는 것을 권장합니다. isDefault가 true로 설정된 동일한 배포에 설정되어야 합니다. 선택 사항이지만 최소 하나의 배포에서 필수입니다.",
}
```
    <Tip>
    `langgraph dev`를 통해 로컬에서 에이전트를 실행하는 경우, `id`(프로젝트 ID)와 `tenantId`는 `uuid.uuid4()`로 생성된 것과 같은 유효한 UUID 버전 4여야 합니다. 각 그래프가 고유한 `id`를 갖고, 모든 그래프가 동일한 `tenantId`를 공유하도록 하세요.
    </Tip>

## 프로젝트 및 테넌트 ID 찾기

LangSmith에 배포된 에이전트의 프로젝트 및 테넌트 ID를 쉽게 찾으려면 배포 URL의 `/info` 엔드포인트에 GET 요청을 하세요. 그런 다음 `project_id` 값을 `id`로, `tenant_id`를 `tenantId`로 복사합니다.

## 환경 변수 설정

Open Agent Platform 인스턴스에 포함하려는 각 배포에 대해 이러한 값으로 JSON 객체를 구성한 후, 단일 플랫 배열로 문자열화한 다음 `apps/web/` 디렉터리 내의 `NEXT_PUBLIC_DEPLOYMENTS` 환경 변수 아래에 설정해야 합니다.

다음은 단일 로컬 배포에 대해 이 변수가 어떻게 보이는지에 대한 예시입니다:

```bash
NEXT_PUBLIC_DEPLOYMENTS=[{"id":"bf63dc89-1de7-4a65-8336-af9ecda479d6","deploymentUrl":"http://localhost:2024","tenantId":"42d732b3-1324-4226-9fe9-513044dceb58","name":"Local deployment","isDefault":true,"defaultGraphId":"agent"}]
```
