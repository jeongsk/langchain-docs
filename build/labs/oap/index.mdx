## Open Agent Platform이란?

Open Agent Platform은 LangGraph 에이전트를 생성, 관리, 상호작용할 수 있는 현대적인 웹 기반 인터페이스를 제공합니다. 단순성을 염두에 두고 설계되어 기술 전문 지식이 없는 사용자도 쉽게 접근할 수 있으면서도, 개발자를 위한 고급 기능을 제공합니다.

## 주요 기능

- **에이전트 관리**: 직관적인 인터페이스를 통해 에이전트를 구축, 구성, 상호작용할 수 있습니다
- **RAG 통합**: [LangConnect](https://github.com/langchain-ai/langconnect)를 사용한 검색 증강 생성(Retrieval Augmented Generation)에 대한 일급 지원을 제공합니다
- **MCP 도구**: MCP 서버를 통해 에이전트를 외부 도구에 연결할 수 있습니다
- **에이전트 감독**: Agent Supervisor를 통해 여러 에이전트가 함께 작업하도록 조율할 수 있습니다
- **인증**: 내장된 인증 및 액세스 제어 기능을 제공합니다
