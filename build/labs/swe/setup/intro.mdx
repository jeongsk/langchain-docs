## 기술 스택

Open SWE는 확장성과 개발자 경험을 위해 설계된 최신 기술로 구축되었습니다:

### 핵심 기술

- **TypeScript** - 전체 코드베이스에 걸친 엄격한 타입 안전성
- **Yarn** - 워크스페이스 지원이 포함된 패키지 매니저 (v3.5.1)
- **Turbo** - 모노레포 빌드 오케스트레이션 및 태스크 실행

### 에이전트 인프라

- **LangGraph** - 세 가지 전문화된 그래프로 구성된 멀티 에이전트 오케스트레이션 프레임워크:
  - 사용자 상호작용 오케스트레이션을 위한 Manager 그래프
  - 실행 계획 생성을 위한 Planner 그래프
  - 코드 변경 실행을 위한 Programmer 그래프
- **Daytona** - 안전한 코드 실행을 위한 샌드박스 개발 환경

### 웹 애플리케이션

- **Next.js** - App Router를 사용하는 React 프레임워크
- **Shadcn UI** - Radix UI 프리미티브 기반으로 구축된 컴포넌트 라이브러리
- **Tailwind CSS** - 유틸리티 우선 CSS 프레임워크

### 문서화

- **Mintlify** - MDX 지원이 포함된 문서화 플랫폼

## 모노레포 구조

<Note>
  Open SWE는 세 개의 주요 애플리케이션과 공통 유틸리티 및 타입을 위한 공유 패키지가 포함된 Yarn 워크스페이스 모노레포를 사용합니다.
</Note>

- **`apps/open-swe`** - LangGraph 에이전트 애플리케이션
- **`apps/web`** - Next.js 웹 인터페이스
- **`apps/docs`** - Mintlify 문서 사이트
- **`packages/shared`** - 공유 유틸리티, 타입, 상수

모노레포는 Turbo에 의해 오케스트레이션되며, Turbo는 패키지 간 빌드 의존성과 병렬 태스크 실행을 처리합니다.
